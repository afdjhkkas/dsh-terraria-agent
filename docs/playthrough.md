## 关键操作经验（踩过的坑，别再犯）

| 现象 | 真因 | 正确做法 |
|---|---|---|
| 移动"卡住" | 玩家身体占 **4 行**（中心±2，含脚下），我用 `round(center)` 只查 3 行，漏掉头顶那格 | 用 `scan` 拿整张实心图，按 4 行判断，挡路块**从上往下挖穿**，走完验证位移 |
| 放置被拒 | 目标格没有**实心支撑**，或放了植物/墓碑（是 tile 但不是支撑） | `tile.solid` 判定支撑；只能放在地面/平台上，且在 5 格内 |
| 放置后瞬间消失 | 多格家具用 `PlaceTile` 放不上 | 家具走 `WorldGen.PlaceObject` |
| 后台挖矿无效 | 单人失焦时 `Main.DoUpdate` 整帧早退（`gamePaused=true`），任何钩子都不跑 | 模组后台线程顶住 `Main.hasFocus`，世界照常 tick |
| 伪造输入无效 | `ItemCheck` 只读 `control*`，且失焦时 `SetControls` 被跳过 | 挖掘直接调 `Player.PickTile`（原版挥镐内部就是它） |
| 单人 vs 多人 | 单人：速度移动有效、失焦会暂停；多人：不暂停、但位置被服务器同步覆盖 | 单人 + 顶住 hasFocus（当前方案） |
