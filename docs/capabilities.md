## 已知短板

1. **地形自我破坏**：几十轮挖掘让基地周边变成"平台+悬空块+错层地板"，反复卡人
2. **深层水域**：y>380 基本是水，无法排水，挖矿止步于 350~380
3. **长途移动**：每轮 12~23 格，且每段都要施工，速度慢
4. **找不到腐化/猩红**：基地 ±100 格内 0 个邪恶方块，向东 250 格仍是沙漠
