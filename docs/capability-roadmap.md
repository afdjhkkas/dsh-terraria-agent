# 能力路线图：从「能活着」到「和玩家一起玩」

> 这份文档回答一个问题：**要在这个世界里当一个合格的玩家（尤其是一个能听人指挥的玩家），
> 我需要哪些能力？现在有哪些是真的？**
>
> 分工：本文是**计划**（要做什么、为什么、验收标准）；
> 已经做完并且有实测证据的，统一记在 [`capabilities.md`](capabilities.md)（唯一的权威清单）；
> 最近一轮的进度摘要见 [`../STATUS.md`](../STATUS.md)。

用户 2026-10-25 的方向修正（原文）：

> 「你应该先总览整个游戏流程，把你需要的能力列出来并写好（遵循真实操作），
> 然后我进入世界指导你跟我玩，你利用能力完成我的要求，而不是现在急于让你通关游戏。」

所以：**先能力，后通关**。目标是"人说什么，我做得到"，而不是"我能不能自己打完"。

## 1. 全流程总览（我需要在每个阶段"能做什么"）

泰拉瑞亚的流程是"装备门槛 → BOSS 门槛 → 世界状态变化"的链条。下表是**玩家真实会走的顺序**，
以及每个阶段我必须具备的能力。

| # | 阶段 | 玩家在干什么 | 硬门槛 | 我要会什么 |
|---|---|---|---|---|
| 1 | 落地生存 | 砍树、搭木屋、放篝火、躲第一夜 | 木材、火把 | 砍树、放置、造房、夜间自保 |
| 2 | 招 NPC | 造合格房间招向导/商人 | 房间合法（墙+门+家具+光源） | 房间判定、家具摆放、墙纸 |
| 3 | 金属时代 | 挖铜/铁/银/金，做铁甲、镐 | 镐的挖掘力、氧气/水线 | 定向下挖、避水、批量采矿、熔炼 |
| 4 | 首个 BOSS | 克苏鲁之眼/史莱姆王/世吞者 | 召唤物（晶状体/皇冠/腐肉）、平台场地 | 召唤、平台建造、BOSS 战走位与输出 |
| 5 | 地牢与地狱 | 骷髅王、狱石、熔岩镐 | 黑曜石皮药水（抗岩浆）、地牢守卫 | 潜水/抗岩浆、长距离运输、地牢探索 |
| 6 | 血肉之墙 | 铺地狱跑道、打 WoF | 跑道、远程武器 | 长直建造、BOSS 风筝 |
| 7 | 困难模式 | 机械三王 → 神圣/魔矿 → 丛林 → 神庙 → 邪教徒 → 四柱 → 月亮领主 | 每级装备、场地、药水 | 全部上面能力的叠加 + 多目标战斗 |
| 8 | 支线 | 钓鱼、染料、召唤、建筑、事件（哥布林/血月/雪人/南瓜月） | 各自的前置 | 钓鱼、事件应对、装饰建造 |

**结论**：前 3 个阶段的能力是地基，我目前大致覆盖到"阶段 3 的一半"（能挖、能造、能打小怪、
能交易），BOSS 阶段几乎是空白。

## 2. 和人一起玩（co-play）的额外要求

人进来之后，我不是"自己通关的 AI"，而是**队友**。队友要满足的是"指令响应"：

| 要求 | 为什么 | 现状 |
|---|---|---|
| **跟随**：走到玩家身边（比如 3~5 格），不要挡在门口 | 人要带路 | ✅ `follow`（只写 control/速度，碰撞重力由原版算） |
| **待命**：站在原地不动，怪来了才还手 | 人在造东西时我不能乱跑 | ✅ `idle` |
| **听令采集**：`挖 30 个铁给我` → 自己找矿、挖、捡、回来交 | 这是最常用的指令 | 🟡 有 `mine`/`grab`/`find`，但没有"任务化采集" |
| **共享仓库**：`把矿放进箱子` / `拿 20 个木头出来` | 人多要分工储存 | 🟡 `chest` 有存取，但没做过"分类+容量"验证 |
| **护卫**：跟着人打，优先打人正在打的怪，血低自己后撤喝药 | 战斗是双人游戏的核心 | 🟡 `follow guard:true` 已优先打队友目标（读 `NPC.target`）、血 <30% 停手；仍不会走位 |
| **让路/不抢物品** | 别抢队友的掉落 | ❌ |
| **报告**：用聊天框说"挖到了 12 个铁" | 人才知道进度 | 🟡 `chat` 能发，但没接入任务流程 |
| **不拖后腿**：卡住/掉坑/死亡要自己恢复 | 双人游戏最怕队友挂机 | 🟡 有魔镜回城、有探水，但没有"卡住自检" |

**多人环境的技术差异**（已实测）：本世界是 `netMode=1`（Host & Play）。在这个模式下
`Player.GetItem` 对**服务端权威**的物品有些路径不生效，掉落物拾取要走原版拾取管线；
`Main.tile` 只在玩家附近加载（±100 格）——**别人在远处看到的地形我看不到**。

## 4. 优先级（按"人下指令时最常要的"排序）

| 优先级 | 能力 | 人的原话会是什么 | 需要新建 |
|---|---|---|---|
| **P0** | 跟随 + 待命 | "跟着我" / "在这等着" | `follow {player}`、`idle` |
| **P0** | 听令采集 | "去挖 30 个铁给我" | `harvest {item,count}`：找矿→挖→捡→回家→报告 |
| **P0** | 进度报告 | "挖好了吗" | 任务状态查询 + `chat` 汇报 |

## 5. 本轮之后要做的实现清单（按上面的优先级）

1. ✅ `follow`：目标 = 某个玩家（`Player.whoAmI`），每帧看距离，>range 格就走、近了停；`guard:true` 兼护卫。
2. ✅ `idle`：清空控制标志 + 取消 path/walk/攻击/跟随。
3. ⬜ `harvest`（下一步）：参数 `{itemType,count}`；循环 = `find` 最近的该矿 → 走过去 → 挖 → `grab` → 数量达标 → 回城 → 报告。
4. `store` / `take`：按 `chest` 坐标 + 物品过滤，把匹配物品塞进/取出，回读校验数量。
5. ✅ `guard`（follow 的一部分）：每 250ms 选队友正在打的目标（`NPC.target`），否则最近的敌对目标。
6. `make`：`recipes` 反查 → 检查材料 → 缺料则报告 → 找最近工作站 → `craft`。

每条都要有"验收证据"：任务结束后打印数量变化（`inventory` 前后 diff）。
