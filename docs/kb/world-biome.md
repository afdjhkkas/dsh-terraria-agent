# 世界与生物群系知识库（world_biome）

> **只写通用机制**：任何世界种子都成立。具体世界的坐标、矿脉位置、水层高度不写在这里。
> 数值来源：官方 Wiki 各条目（分层、生物群系、液体、扩散）；与代码常量冲突时以游戏内 `api` 为准。

---

## 1. 世界分层（按深度百分比，不按固定高度）

从上到下：**太空 → 地表 → 地下（土石层）→ 洞穴层 → 地狱**。

- 分层边界由世界高度按比例决定，所以不同尺寸的世界，同一"层"的绝对高度不同。
- **地表**约在世界高度 27%~35% 处，是草地/沙/雪/丛林的地带。
- **地下层**紧贴地表之下，以土为主，穿插洞穴。
- **洞穴层**更深，以石为主，背景墙变暗；矿物与水晶开始密集。
- **地狱**在最底部（约占最下 5%），整片是岩浆海与灰烬。
- 太空在世界顶部，气压低（跳跃更高、重力感不同），有坠落星与鸟妖。
- 判断"自己在哪一层"用 `state.zones`，不要用固定数字去猜。

## 2. 生物群系怎么判定

一个生物群系的核心是**该群系专属方块/草地达到足够数量**（每个群系的阈值是引擎常量）。

- **森林**是默认：没被别的群系覆盖就是森林。
- **沙漠**：沙子成片；**雪原**：雪块/冰块成片；**丛林**：丛林草 + 丛林藤 + 泥；**蘑菇地**：发光蘑菇草；**海洋**：世界左右两端的天然水域；**太空**：地表以上足够高。
- **腐化/猩红/神圣**是"侵染型"群系：靠特定方块（腐化石/黑檀石、猩红石、珍珠石）成片存在，会随时间扩张。
- 一个区域可以**同时满足多个群系**（例如雪原里的腐化），游戏按优先级取一个显示，但方块属性都生效。
- 生物群系影响：刷什么怪、能钓到什么、NPC 幸福度、部分物品能否合成/使用。

## 3. 液体、窒息、坠落

- **水**：可游泳，减速；淹过头会消耗呼吸。
- **岩浆**：接触即受伤（对玩家约 80 点、对怪物约 50 点），并附加"着火的！"；
  沾岩浆的物块会点燃玩家。饰品能大幅降低或免疫（黑曜石玫瑰一类）。
- **蜂蜜**：极黏，移动很慢，也会消耗呼吸；能回血（缓慢）。
- **水 + 岩浆 = 黑曜石**；**蜂蜜 + 岩浆 = 松脆蜂蜜块**。液体不会凭空消失，只会被方块挤占。
- **呼吸**：头部浸入水/蜂蜜（不是岩浆）后开始憋气，裸装约二十多秒，气泡见底开始掉血；
  潜水装备能显著延长时间。**上游出水面立刻恢复**。
- **坠落伤害**：落差不超过 25 格不受伤；超过后**每多一格多 10 点**。
  云朵瓶/幸运马掌/翅膀能免疫或减免。

## 4. 环境扩散（腐化 / 猩红 / 神圣）

- 三种侵染群系都靠**草地**和**石块/沙**传播：侵染草地能把**相邻 3 格内的土块**也转化。
- 只隔一道 1 格厚的普通方块**挡不住**（草地按半径 3 格转化），做隔离带要够厚、且用**不可被转化的材料**。
- **荆棘/藤蔓**会把侵染带向外推进，且只在地表以上起作用；砍掉地表植被能减缓扩散。
- 困难模式会**加速**：石块本身开始被转化，天空出现神圣/腐化飞地。
- 对抗手段：净化粉（小范围）、圣水/邪恶粉末（反向制造）、向日葵（压制腐化）、
  以及困难模式后的蒸汽朋克 NPC 卖的净化器。

## 5. 昼夜、月相、天气

- **白天与夜晚**大致各占一半时间；夜晚刷怪更凶、部分首领只在夜里可召唤。
- **月相**按天循环，影响部分物品掉落（如某些怪物只在新月/满月出现）与 NPC 出售。
- **天气**：雨、暴雪、沙尘暴。雨会加强部分刷怪、影响钓鱼产物；暴雪限于雪原；沙尘暴限于沙漠。
- **血月**：夜晚随机触发（也可用血泪召唤），刷怪暴增、部分 NPC 有特殊出售。
- **日食**：困难模式白天事件，刷特定怪物（掉落"破晓之光"一类材料）。
- 事件（哥布林入侵、史莱姆雨、海盗入侵、南瓜月、霜月）会**替换**普通刷怪表。

## 6. 地貌结构（走到会看见什么）

- **地下小屋**：木板墙 + 木平台 + 陶罐 + 一个宝箱；是早期装备与钱的主要来源。
- **生命水晶**：洞穴层成簇出现，每颗 +20 生命上限，用到 200 为止（之后要靠生命果）。
- **浮空岛**：天上有小岛，含"天域宝箱"（星怒、云朵瓶一类）与天域砖。
- **金字塔**：沙漠里，含砂岩宝箱与陷阱。
- **蜂巢**：地下丛林，含幼虫（召唤蜂王）与蜂蜜。
- **地牢**：世界一侧的地下巨型砖构，需要先打败骷髅王才能安全深入；含锁着的金箱（用金钥匙开）。
- **地狱废墟**：地狱里的黑曜石砖建筑，含暗影宝箱（需要暗影钥匙）与熔炉。
- **发光蘑菇地**、**沙漠地下**（沙岩箱）、**冰雪地下**（冰霜箱）各有专属战利品。

## 7. 速查（问"这里是什么/会怎样"时先看这里）

| 问题 | 判定 |
|---|---|
| 这是哪一层 | `state.zones` 里的 under/rock/hell/sky/surface 等标记 |
| 这是什么群系 | 看该群系专属方块是否成片；`state.zones` 会给当前判定 |
| 能不能潜水过去 | 头会不会入水；裸装只有二十几秒 |
| 跳下去会不会摔死 | 落差 >25 格开始受伤，每多一格多 10 点 |
| 岩浆碰一下多少 | 对玩家约 80 点并着火，对怪物约 50 点 |
| 腐化会不会扩散过来 | 会；草地按 3 格半径转化，1 格厚墙挡不住 |
| 这里为什么刷怪多 | 深处 + 夜晚 + 无人工墙 + 无城镇 NPC |
