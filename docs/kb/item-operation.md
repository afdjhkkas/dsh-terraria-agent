# 物品与操作能力知识库（item_operation）

> **只写物品本身的通用逻辑**：什么物品能干什么、什么不能干、用之前要满足什么条件。
> 不写具体世界的坐标、不写我们某个工具的参数表（那是接口文档，见 `_generated-commands.md`）。

---

## 1. 物品分类与功能边界

| 类别 | 能做什么 | 不能做什么 |
|---|---|---|
| **镐** | 移除硬质前景方块（石、矿、砖、土等） | 不能放置方块、不能砍树、不能改方块外形 |
| **斧** | 砍伐树木与植被、拆木质家具、部分背景墙 | 不能挖矿、不能放置；树干是**多击**物体（一棵普通树要连击数次才断） |
| **锤** | 改方块外形（斜面/半砖/转角）、拆背景墙、拆家具 | 不能挖硬质方块（锤力远低于镐） |
| **方块类物品** | 放置前景实心方块，用于搭建/回填/封路 | 不能当镐用 |
| **背景墙物品** | 铺设背景墙（视觉 + 阻止刷怪 + 房屋判定必需） | 不能当实心方块挡路 |
| **光源物品** | 放置火把/灯/蜡烛/篝火，照明 + 满足房屋光源条件 | 不是家具，不能替代桌椅 |
| **家具物品** | 门、桌椅、床、箱子、工作台、熔炉等 | 多格家具有固定占地与锚点，位置不对放不下 |
| **平台/轨道** | 可穿行的水平通路 | 不是封闭方块，做屋顶或外墙会导致房屋无效 |
| **远程武器 + 弹药** | 消耗弹药造成伤害；弓/枪/发射器各有对应弹药 | 没弹药就完全不能攻击 |
| **近战武器** | 挥击造成伤害，多数可同时挖弱方块 | 打不到远处目标 |
| **召唤物武器** | 召唤随从自动攻击 | 受召唤栏位上限约束 |
| **抓钩/钩爪** | 把角色拉向可抓表面 | 抓不到空气/水面；有射程上限 |
| **翅膀/坐骑** | 飞行、二段加速、长距离移动 | 受飞行时间/高度上限约束 |
| **药水/食物** | 提供增益、治疗、照明、水下呼吸等 | 有共享冷却与持续时间，不能无限连喝 |
| **爆炸物** | 大范围破坏方块 | 会伤到自己、会破坏建筑、需要小心引信 |
| **放置型机关/电路** | 触发线、压力板、门、泵等 | 需要正确连线才生效 |

**通用判断顺序**：先看**分类**（这东西属于哪一类）→ 再看**等级**（镐力/锤力/伤害是否够）→ 最后看**条件**（弹药、栏位、冷却、站位）。

## 2. 物品使用硬性约束

- **镐不能放方块，方块不能挖物块**；外形修改只能用锤子。
- **清理植被/背景墙优先用斧头**；用镐也能拆除树格，但**不掉木头**——表现为“格子消失了、材料一点没涨”，很容易被误判成“掉落到别处了”。
- **能砍的格子不等于能一击断**：砍伐是伤害累积过程，必须循环挥击并回读格子，看到格子消失才算砍下；只挥一次就断言“砍不动”是错的。
- **铺设背景墙只能用背景墙类物品**；实心方块不会变成墙。
- **光源与家具必须用对应分类物品放置**，不能拿别的物品顶替。
- **合成站有作用范围**：人离工作站太远（横向或纵向都算）时，配方会报“附近没有这个工作台/熔炉”，这不是缺材料而是站位问题——先走到工作站旁边再合成。
- **丢弃不等于腾出空位**：掉落物会被自动拾取吸回背包，空出一个格子立刻又把刚丢的东西捡回来，所以“丢了之后背包又满了”是预期行为。真正要销毁只能用背包里的垃圾桶栏位。
- **远程武器必须有匹配弹药**；弹药耗尽后无法攻击。
- **召唤物受栏位上限**，超出后再召唤不会生效。
- **治疗类药水有共享冷却**：刚喝完再喝会失败，要等冷却结束。
- **多格家具需要足够空间与正确支撑**（下方实心、上方留空），空间不够就是放不下。
- **方块需要支撑或允许悬空**；悬空放置会失败，除非该方块本身允许。
- **不可逆操作要慎重**：拆掉承重结构会让上方整体掉落/塌方，爆炸物会连带毁掉周边。
- **消耗品和挥动类是两条使用分支**：镐斧锤剑弓与投掷物靠"起手动画"驱动，而生命水晶、药水、召唤物要求使用瞬间动画为 0 才会走"吃掉并生效"。给消耗品强行播动画＝永久的空挥：命令回 ok、物品还在、上限/血量一点没涨。判断依据很简单——回读前后对比物品数量与属性，没变就是没吃到。
- **"用了"必须由回读证明**：消耗品看堆叠数减没减、生命水晶看生命上限涨没涨（+20/颗，上限 200），药水看血量与冷却。只看命令返回 ok 会漏掉上面那条分支错误。

## 3. 背包与切换逻辑

- **动手前先校验背包**：这个任务需要什么物品、在不在包里、够不够用。
- **缺少必要物品就停止任务并说明缺什么**，不要硬着头皮继续做没有意义的动作。
- **同一阶段只做同类操作**：连着挖就一路挖，连着放就一路放；频繁换物品既慢又容易出错。
- **移动过程中不做精细操作**：走/跳的时候不挖、不放，先停稳再动手。
- **背包会满**：空间不足时掉落物拾取会失败，先把不用的东西存起来或丢掉。
- **切换物品要确认真的切换了**：看当前手持物，而不是以为切了。
- **材料预留**：合成前先算清配方需求，避免把关键材料用光（锭、召唤物、稀有矿石）。

### 主栏怎么排（真人录像结论）

- **没有固定排法**。真人自己说的是「需要什么就打开背包拿什么」，不存在一套通吃的顺序。
- 真实模式是：**工具位固定（镐/剑/斧/锤/弓 各占一格），最后一格当"当前工作位"**
  —— 临时换成要用的那样东西（土块、火把、药水、绳子），用完再换下一个。
  录像里同一个格子在一分钟内换过 4 种物品，这是正常用法，不是乱放。
- **点击背包里的物品会直接把它拿到手上**（不必先拖进主栏再切）。急用时点一下比拖快。
- 换物品的代价是"手上东西变了"：换之前确认新物品适合当前场景（挖矿拿镐、打架拿剑/弓）。
- 因此评估"操作像不像人"时**不能拿主栏顺序当判据**；该看的是"当前手上这格是不是这件事要用的"。

### 堆叠拆分与合并

- 拆一组物品：**拆出数量被夹在 1..该堆总数-1**，拆出来的那份进**第一个空格**（`splitstack {slot,count}`；实测：一堆 3 个、请求拆 60，实际只拆 2、剩 1）。
- 拆分是**背包内部搬运**：不需要工作台、不消耗耐久、不受距离限制；背包满时必然失败（没有空格放另一半），先腾格子。
- 要合回一组，最稳的是**丢到地上再捡回来**（落地物重新入包会自动叠同种物品），比手动挪格子可靠。

## 4. 交互站位规则

- **挖掘/放置必须在交互范围内**：超出距离会失败，先走过去再动手。
- **目标格被遮挡时**（中间隔着方块），先清出通路或换一侧站位，不要盲点。
- **站姿要稳**：脚下有支撑、头顶不卡、左右不被挤；站在斜坡/半砖上容易滑。
- **多格家具先站到锚点附近**：锚点不对会放成别的朝向或直接失败。
- **和 NPC 交互前先站到平整无遮挡的位置**，交互过程中保持静止。
- **危险地形**（岩浆边、深水、悬崖）操作前先确认退路，必要时先砌护栏。
- **狭窄竖井里操作**：先确认自己所站的格子是稳的，再动旁边一格，避免把自己埋进方块里。
## 5. 常用 ID 速查

两条最容易搞错的：

- **物品 id ≠ 物块 id**。石块物品 3 放下变成物块 1；木材物品 9 放下变成物块 30。
  拿物品 id 去 `place` 会报"背包里没有能放成方块 X 的物品"。
- **背景墙另有一套 id**，和物块 id 不通用；穿墙洞、砌背墙各查各的。

## 放置与挖掘都按结果收手，别猜时长

不同方块硬度差很多，同一种方块在不同工具下也不一样，所以"按多久"不是可记的参数。
正确做法是按住不放，让游戏按挥动冷却自己推进，然后**回读那一格**：
挖到变空、或放到变实体，立刻收手。

判断的唯一依据是回读结果，不是时间。固定时长必然在某些方块上不够、在另一些上白按。

## 玩家身体占着的格子放不下东西

放置的落点如果和角色身体重叠，原版会拒绝——表现为"命令成功了但格子还是空的"。
站在哪里就决定了哪几格放不了：贴身那两格永远放不进去，要往旁边让一两格。
