# 游戏规则库（game_rule）

> 什么时候加载：问"为什么不行 / 能不能 / 游戏是怎么算的"。
> 标注约定：`已验证` = 本仓库/本档有回读证据（写在证据列）；`未验证` = wiki 或推断，**用之前必须先测一次**。
> 全部数值要么带证据，要么标 `未验证`；不要凭印象补。

## 1. 世界机制规则

| 规则 | 状态 | 证据 |
|---|---|---|
| 本档世界 4200×1200（小世界）、`height 1200`、`hardmode:false` | 已验证 | `state` → `world{width,height,hardmode}` |
| 地表在 y≈300（脚下地板 y=303~305），出生点 (2099.5,303.7) | 已验证 | `state.player.tile`；`tile` 读 303 行是木/土 |
| `Main.tile` 只在已加载区有效（约玩家 ±100 格），远处读回 `-1/air` | 已验证 | 远处 `tile` 恒 `hasTile:false`；`find` 在 400×140 区能扫、跨千格必空 |
| `find` 返回 0 **不等于**没有：先看扫描区间是否在加载区 | 已验证 | 同一条矿脉，走近后 `find` 才有结果 |
| 桥跑在客户端 `netMode=1`，世界变更由服务端广播，回读会滞后 | 已验证 | `place` 后立刻 `tile` 偶尔仍旧值，300~1500ms 后才稳定 |
| 死亡 → 满血在出生点复活，**物品不丢** | 已验证 | 多次死亡前后 `inventory` 一致 |
| 昼夜/天气影响刷怪；**夜晚 + 下雨 = 最高刷怪** | 已验证 | `world{dayTime:false,raining:true}` 下站着不动：0s 100% → 16s 80% → 24s 0% |
| 时间流速 ≈ 481/8 秒；到白天（54000）约 7 分钟 | 已验证 | `time` 连续采样 |
| 本机 **没有**开"失去焦点暂停"：`hasFocus:false` 时 `tick` 仍在涨、角色仍能动 | 已验证 | `state{hasFocus:false,tick}` 持续增长 |
| 最小化窗口也不暂停（tick 继续） | 已验证 | 见 terrarria-mechanics §Pausing |
| `zones` 可判群系（corrupt/crimson/jungle/snow/desert/beach/dungeon/glowshroom/meteor/hallow/underworld/rocklayer/dirtlayer/sky/surface） | 已验证 | `state.player.zones` |
| Journey 模式：`research` 到 100/100 后 `duplicate` 可无限取 | 已验证 | 石块 100/100 → `duplicate` +900/次 |
| `save` 命令会 NRE（`Main.SaveWorld`），**不要依赖** | 已验证（bug） | 调用直接异常；正常关窗口时游戏自己会存 |
| 强制放置（`WorldGen.PlaceTile(forced:true)`）**重启后消失**；真实物品流放置的会留存 | 已验证 | 3 方块 + 1 墙真实放置重启后都在；2 格强制放置都消失 |
| 杀 `dotnet.exe` 宿主会丢存档；必须向 **游戏窗口**发 `WM_CLOSE` 让它自己退 | 已验证 | 见 mechanics §Persistence |
| `WorldGen.StartRoomCheck/CheckRoom/ScoreRoom/moveRoom` 在本档不可用 | 已验证（bug） | 见 §3.2 |

## 2. 方块与物块属性规则

### 2.1 编号三类，别混

| 概念 | 谁在用 |
|---|---|
| **物品 ID**（`ItemID`，背包里的 stack） | `craft {item}`、`equip {item}`、`buy/sell` |
| **方块 ID**（`TileID`，地图上的 tile） | `place {type}`、`fill {type}`、`find {type}`、`scan` 的 `type` |
| **墙 ID**（`WallID`） | `tile.wall`、`wall {x,y,type}` |

已核对的物品↔方块对照：石 物品 3 → tile 1；木 物品 9 → tile 30；土 物品 2 → tile 0；木门 物品 25 → tile 10。

### 2.2 方块 ID（本档逐个 `tile` 读回确认过）

| 方块 | ID | 备注 / 证据 |
|---|---|---|
| 土 / 石 / 木材 | 0 / 1 / 30 | `tile` 读回 `name:"Dirt"/"Stone"/"WoodBlock"` |
| 火把 | 4 | 房屋光源；`find type:4` 数火把 |
| 关闭的门 / 打开的门 | 10 / 11 | 占 3 格高，锚点 = **底部格** |
| 桌子 / 椅子 / 工作台 | 14 / 15 / 18 | 房屋的"平坦面 / 舒适物" |
| 铁砧 | 16 | 2×1，锚点 = 左下 |
| 熔炉 | 17 | 3×2，锚点 = **底部中间**（曾瞄 (2081,303) 占 (2080..2082,302..303)） |
| 平台 | 19 | `solidTop`，**不算封闭**，只能当场地 |
| 金箱 | 21 | `find type:21` 定位过 4 个（都在深部 y≈456） |
| 恶魔祭坛 | 26 | 腐化/猩红地下；克苏鲁之眼召唤物用它 |
| 墓碑 | 85 | 不挡路但会遮判定，清掉 |
| 绳子 | 213 | 攀爬；中心对齐 `col+0.5` |
| **铁矿** | **6** | `tile(1952,339)` → `{type:6,name:"Iron"}` |
| **银矿** | **9** | `tile(1906,380)` → `{type:9,name:"Silver"}` |
| **锡矿** | **166** | `tile(1927,361)` → `{type:166,name:"Tin"}` |
| 铜 / 金 / 铅 / 铂 / 钨（8 / 167 / 168 / 169 / 203 / 204 / 205） | — | 同区间 `find` 全 0；**别再拿 203 当铁矿**（旧笔记错了，已更正） |

> 教训：矿石 ID 必须 `find` 到具体坐标后 `tile` 读 `name` 确认，不要从记忆/表格里猜。

### 2.3 硬度与挖掘时间

- 铁镐挖丛林草 / 冰雪 / 石头 ≈ **1.2~1.3 秒** → `mine` 的 `ms` 默认 1300；给 900 会"返回成功但方块不动"。`已验证`
- 挥镐会自动换手里最合适的镐/斧；但**打完会留在镐上**，不会自动切回武器（`mine` 会改手持）。`已验证`
- 挖一格前先 `tile`：`hasTile:false` 就别挥（省 1.3 秒）。

### 2.4 液体 / 绳子 / 斜坡 / 平台

| 规则 | 状态 | 说明 |
|---|---|---|
| 液体薄层（`liquid` 122~198）可趟；满格或连片水腔（≥240）会溺水 | 已验证 | 破土前探脚下 3 行两列 |
| 水**不能被方块挤出** | 已验证 | 往水里放方块 9 次全失败（无支撑 + 液体格拒绝放置） |
| 绳子要中心对齐 `col+0.5` 才攀爬 | 已验证 | 偏一格爬不动；`climb` 只认绳子 |
| 空腔里挂不了绳（无支撑） | 已验证 | 深坑底部无法自建绳道 |
| 斜坡（`slope` 1~5）/ 半砖改变站立高度 | 已验证 | 放置后"放上去却站不住"多半是它 |
| 平台 `solidTop`：能站不能封 | 已验证 | 用平台做屋顶/墙 → 房屋必判无效 |
| 破坏方块**不会**移除背后的墙 | 已验证 | 墙驱动房屋判定与光照 |

### 2.5 掉落物

| 规则 | 状态 | 证据 |
|---|---|---|
| 挖出来的东西掉在**被挖的格子上**，不会自动入包 | 已验证 | 挖 6 格后 `items` 能看到，`inventory` 没变 |
| 拾取半径约 **4 格**（脚边），远处 `items` 能看到但 `grab` 拿不到 | 已验证 | `grab {r:12}` 返回 `picked:0` |
| **主背包满（50/50）时拾取静默失败** | 已验证 | `main_slots_used:50` 时 `grab` 一直 0，丢 8 格后立刻能捡 |
| 掉落物会消失（超时/地形变化） | 已验证 | 走开后回去已不见 |

## 3. NPC 入住 / 生成规则

### 3.1 房屋有效的条件（原版规则）

| 条件 | 阈值 |
|---|---|
| 内部空腔 | **60 ~ 7500** 格（7500 是上限，不是 750） |
| 四周封闭 | 实体方块或门；**任何一格漏（平台、门上空洞）都不合法** |
| 背墙 | 内部每格 `wall > 0` |
| 地板 / 天花板 / 左右墙 | 连续实心，不能断 |
| 家具 | ≥1 平坦面（桌 14 / 工作台 18 / 梳妆台）+ ≥1 舒适物（椅 15 / 凳 / 王座） |
| 光源 | ≥1（火把 4 / 蜡烛 / 吊灯 / 营火） |
| 环境 | 不能在腐化/猩红/地牢/神圣（`zones` 可判） |

### 3.2 本档的判定链路（重要，别再踩）

| 事实 | 状态 | 证据 |
|---|---|---|
| 引擎 `CheckRoom` 在本档**不可用**：合法房也报 `HoleInWallIsTooBig`（reasonValue 4） | 已验证 | 自算 74 格封闭的房 → 引擎 `tiles=17` |
| 引擎 `numRoomTiles` 随种子乱跳，`box` 永远往西/北漏到固定坐标（2102 / 297） | 已验证 | 种子 (2104,299)/(2118,303)/(2123,301) → tiles 3 / 27 / 11 |
| 逐格 `tile` 与 `scan` 读数一致 → 不是坐标系问题 | 已验证 | 5 个关键格两边一致 |
| `moveRoom` 因此静默失败：`moved:false, reason:"None"`，NPC `homeless` 不变 | 已验证 | `homeroom {x:2112,y:301,who:1}` |
| **唯一可信判据 = 自写 `housediag {x,y}`**（独立洪水填充 + 逐条核对 3.1，只读） | 已验证 | 返回 `tiles:74, enclosed:true, walled:74/74, floor/ceil/left/right:1.00, light:2, comfort:2, flat:2, missing:[], valid:true` |
| 装门真的消耗物品：背包木门 4→3，格上 `type:10` 占 3 格 | 已验证 | 2103 的 301/302/303 |
| 门要装成功：门位 3 格空 + **下方实心** + **上方实心**，缺上方会静默失败（挥一下什么都不发生） | 已验证 | 反复失败后补齐才装上 |
| 房子"看起来合法但没人来"最常见原因是**时钟**（夜间不搬入） | 未验证（wiki） | 待白天观测 |

### 3.3 NPC 行为

- 无家（`homeless:true`）的商人**照样能交易**，只是到处走、容易掉进坑。`已验证`
- 城镇 NPC 会自己开门进屋；**我们驱动的角色不会**（速度式移动不触发原版开门）→ 过门要么挖掉，要么用门上方留口。`已验证`
- 商人入住条件：身上/背包 ≥50 银（wiki）；本档尚未在满足条件时观测到搬入 → `未验证`
- 幸福度影响价格（邻居/环境）；本档未测 → `未验证`

## 4. 怪物刷新机制

| 规则 | 状态 | 说明 / 证据 |
|---|---|---|
| 城镇 NPC 压制附近刷怪：3 个 NPC 时约 **250 格**内基本不刷 | 已验证 | 要走到 ≈290 格才稳定遇怪 |
| 刷怪发生在**屏幕外**（水平约 62~84 格、垂直 10~35 格） | 未验证 | vanilla 数值，本档未测 |
| 静止会略降刷怪率 | 未验证 | 只观察到"站着时怪变少" |
| 夜晚 + 下雨 = 刷怪最高档 | 已验证 | 出生点站着 24 秒被打死 |
| 事件/Boss 可用 `boss` / `event` 查询，有材料才出 | 已验证 | `boss` 返回可召唤列表 |
| 血月/哥布林入侵显著提高刷怪 | 未验证 | 本档未遇到 |

## 8. 游戏内判定标准速查（阈值表）

| 判定 | 阈值 | 命令/字段 |
|---|---|---|
| 房屋有效 | 见 §3.1，用 `housediag` | `housediag {x,y}` |
| 瞄准距离（挖/放） | ≤ **7 格**（实用 4 格） | 报错"够不到：离这一格超过 7 格" |
| 攻击半径 | `attack.r` 硬半径，实用 12~22 | `attack {who,r}` |
| 交战决策 | 只主动打 **8 格内** | — |
| 对话 / 商店 | < 11 格 / < 12 格 | `talk` / `shop` |
| 合成站位 | 工位 ~1 格（宽松到 7 格内部分可用） | `craft` |
| 拾取 | 脚边 ~4 格；背包满则静默失败 | `grab` |
| 死亡 | 满血复活于出生点，物品不丢 | `state.player.dead` |
| 溺水 | 头入水约 10 秒开始掉血 | `state.player.wet/breath` |
| 坠落伤害 | 落 >25 格开始受伤 | `state.player.fallDist`（有则为准） |
| 背包 | 主背包 50 格 | `main_slots_used` |
| 时间 | `time` 每 8 秒 +481；白天 54000 | `state.world.time` |
| 刷怪压制 | 城镇 NPC 周围 ~250 格 | 实测 |
