## 1. 房屋判定规则

判定分三段：**外框 → 家具 → 属性**。任一段不过，NPC 就不会入住，
"?" 查询会直接说缺什么（优先级：前景/背景墙 → 家具 → 其他）。

### 1.1 尺寸与范围（最常被问的一条）

- **总面积：至少 60 格、少于 750 格，含外框那块边框一起算。**
  注意不是只算内部空地——墙、地板、天花板都计入这 60~750。
- 常见最小矩形（宽×高，含框）：
  **5×12**、**6×10**、**7×9**、**8×8**、**9×7**、**10×6**、**12×5**、**15×4**。
  矮房要更宽：3 格高至少要 10 格宽。房屋**不必是矩形**，只要连通且够格数。
- 全部格子必须离**真世界边缘**至少 10 格（正常游玩碰不到，贴着地图边造房才会踩到）。

### 1.2 外框（Frame）与背景墙

- 内部区域按**八方向连通**判定；外框必须把所有内部格和外部彻底隔开。
- 外框只能用这几类拼：**实心方块**、**未制动的平台**、**活板门**、**门**、
  **高门**（只算关门时占的那几格）。
- **"洞"的定义**：某一格既没有有效实心块，也没有有效背景墙。
  **洞的宽或高达到 5 格就判失败**；小于 5 的墙洞是允许的（房间里可以有窗）。
- **玩家放的墙才算数**；自然生成的土墙等不算。
  例外（自带就算数）：浮空岛的盘墙、地下小屋的板墙、金字塔的砂岩砖墙。
- 想让墙上的洞既能透光又不刷怪：用**玻璃墙**填，不要留真空洞。

### 1.3 家具（四类各至少一件）

| 类别 | 作用 | 最小可用组合 |
|---|---|---|
| 光源 | 火把、灯、蜡烛、篝火、吊灯… | **火把** |
| 平面 | 桌、工作台、梳妆台、书架、钢琴、炼金台… | **工作台** |
| 坐具 | 椅、床、马桶、长椅、王座、沙发… | **椅** |
| 入口 | 门、平台、活板门、高门 | **两个平台** |

- 光源**不接受**前景方块、平台、墙这类"看起来亮"的东西，必须是家具类光源。
- 入口**不需要真的能用**（活板门也算），也不必通向室外（室内平台就够）。
- 同类物品任意款式都算（各种颜色的火把、各种主题的椅子都行）。

### 1.4 属性（结构没问题也可能被拒）

1. **已被别的 NPC 占用** → 直接无效。
2. **邪恶评分（evil score）**：以房屋范围为中心向四周扩一圈（代码里左右各扩 45 格、
   上 43 格下 46 格）统计污染方块——腐化/猩红方块每格 +1，神圣方块每格 −1，
   向日葵 −5。**评分达到 50 就无效**；低于 50 时余量 `50 − 评分` 会并进后面的站点评分。
   （该扩大范围在 1.4.2.3 的代码里除错了一次 16，实际扫得比标称小得多，
   所以"房离腐化几格远"没那么容易真的被判失败。）
3. **站点评分（home tile score）**：房里必须有一格能让 NPC 夜里站住——
   该格实心、左右两格实心且未制动、正上方 3×3 无遮挡、正上方 3 格在房内且无前景块。
   再按这一格上方 5×4 区域算分：关着的门 −20/格、门轴 −20/格、无制动实心块 −5/格、
   其他物件 +5/格，加上前面的余量。**最终 ≤0 就无效**。
   所以**房里塞满实心块、箱子、门会把站位分吃光**。

### 1.5 其他判定事实

- **一个封闭空间只算一间房**；想住两个 NPC 就得隔成两间。
  多间房可以**共用墙、地板、天花板、门**——看起来是一栋楼，游戏当成几间独立房。
- 判定与**地下深度、自然光亮度、房间形状、材质贵贱、装修好坏都无关**。
- 床既是坐具，也能当玩家重生点（床上方要空）。
- **蘑菇人**额外要求：房屋周围那一圈里至少有 100 格发光蘑菇方块。
- 房屋被破坏或条件失效后，NPC 会到处游荡，直到出现新的有效房；NPC 被杀后，
  只要有效房恢复就会重生。
- **NPC 不会当着你的面在房里刷出来**：房子在屏幕上时不生成；
  夜里、下雨、事件期间你走远或用魔镜/传送器，NPC 会被直接放回房里。

## 2. NPC 入住与生成规则

- 入住前提三条同时满足：**存在有效空房** + **该 NPC 的解锁条件达成** + **当前没有入侵事件**。
  （例：商人需要玩家身上持有一定数量的银币，并且有一间空房。）
- 房间封闭不全、缺墙、缺光源、开口过大 → 不会入住。
- **一位 NPC 占一间房**，不会与他人合住；房间被破坏后 NPC 会离开。
- **环境偏好**：部分 NPC 对生物群系/高度有要求（例：蘑菇人只住蘑菇地；某些 NPC 偏好地表或地下）。
- **幸福度**按「独居与否 + 邻居是否喜欢 + 所在生物群系 + 拥挤程度」计算，直接影响售价与传送价格；
  不满意会明显涨价。
- **高刷怪区、持续战斗区、地形杂乱区**会降低入住意愿（就近怪物多时容易被反复打断）。
- **入侵/事件期间不会搬入**；事件结束后才恢复。
- NPC 一旦入住，会自己开门、走动、在附近游荡；夜间会回房。

## 3. 怪物刷新规则

- 只在**屏幕外一定距离**、**没有人工背景墙**、**可站立**的位置生成。
- **玩家放置的背景墙**会让该格无法刷怪（俗称"安全墙"），这是最可靠的防刷怪手段。
- **光源**不直接消灭已存在的怪，但会显著降低地表刷怪；大量照明能压住普通怪刷新。
- 刷怪权重随**深度、生物群系、昼夜、天气**变化；地表与地下是两套刷怪池。
- 附近有**城镇 NPC** 时刷怪率下降（城镇安全区）。
- **水蜡烛、战斗药水**提高刷怪；**和平蜡烛**降低刷怪。
- **事件**（血月、日食、哥布林入侵、史莱姆雨等）会替换或叠加普通刷怪表。
- 不同生物群系刷各自专属怪（腐化/猩红/丛林/地牢/雪原/沙漠/地狱各有不同表）。

## 4. 物块与地形规则

- **镐力门槛**：土/木/沙/雪无门槛；石类需要一定镐力；黑曜石、地牢砖、陨石等需要更高镐力；
  狱石需要地狱级镐或炸药。
- **锤子决定外形**：斜面、半砖、转角**只有锤子能改**；部分方块不可形变。
- **沙、雪泥、砂砾受重力下落**；水与岩浆会流动，可以用方块阻断，但**无法把水"挤走"**。
- **掉落物会被自动拾取**：角色附近的地面物品在延迟后自动进入背包；背包满时拾取静默失败。这也意味着“丢东西腾格子”会被自己捡回来。
- **前景方块与背景墙是两套独立判定**：拆前景不影响墙，拆墙不影响方块。
- **平台可穿行**（下键下落）；**门需要交互打开**，靠移动不会自动开门。
- **舞台/平台、玻璃等不是封闭方块**：用它们做屋顶或外墙，房屋判定会失败。
- 树木、仙人掌、蘑菇、藤蔓属于植被：**斧类工具才有产出**，镐能移除但不给材料；树干是多次击打才断裂的多格整体，断掉时整棵一起掉落。

## 5. 环境扩散规则

- **腐化 / 猩红 / 神圣**会通过草、藤蔓、石块互相转化扩散，也会感染沙、冰等。
- **阻断材料**：黏土、灰烬、木材、地牢砖以及各类"不可侵蚀"方块不会被转化。
- **连续无缝的阻断层**能长期挡住蔓延；零星几块挡不住。
- **向日葵**能阻止地表草被转化（范围有限）。
- 困难模式后扩散速度显著加快，并会生成新的感染带。
- 净化手段：净化粉、圣水、环境改造枪，按区域清除。

## 6. 世界全局机制

- **一天 = 24 分钟**（白天 15 分、夜晚 9 分）；夜间刷怪更凶，部分怪只在夜间出现。
- **天气**：雨、雪、沙尘暴；会加强部分刷怪，也影响部分 NPC/生物出现。
- **事件**：血月、日食、史莱姆雨、哥布林入侵、海盗入侵、南瓜月/霜月、四柱等，各有触发与结束条件。
- **Boss 召唤**多数依赖：祭坛（腐化/猩红）、合成召唤物、特定地点/时间、或满足击杀前置。
- **击杀顺序影响世界状态**：例如击败血肉之墙后进入困难模式，矿物与刷怪全面升级。
- **死亡**：普通难度不掉落物品，重生点默认是出生点（可被床改变）。
- 世界生成是**分层的**：天空 → 地表 → 地下 → 洞穴 → 地狱；每层有各自的方块、生物与矿物。

## 7. 判定速查（问"算不算"时先看这里）

| 问题 | 判定 |
|---|---|
| 房屋算不算数 | 60≤含框总面积<750 → 框闭合且洞<5 格 → 光源+平面+坐具+入口齐 → 未被占用、evil<50、有可用站位格 |
| 为什么 NPC 不入住 | 面积不对 / 框有 5 格以上的洞 / 缺某一类家具 / 被别的 NPC 占了 / 邪恶评分过高 / 房里没有可站格 |
| 会不会刷怪 | 有背景墙 / 有城镇 NPC / 照明充足 → 不刷或很少刷 |
| 这个方块能不能挖 | 当前镐力 ≥ 方块要求 |
| 这个位置能不能放 | 有相邻支撑，或该物品允许悬空 |
| 水能不能被方块挤出去 | 不能；只能用方块阻断流向或做排水结构 |
| 污染会不会继续扩散 | 有没有连续的无缝阻断层；困难模式会加快 |
