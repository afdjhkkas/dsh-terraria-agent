> 什么时候加载：问"为什么不行 / 能不能 / 游戏是怎么算的"。
> 标注约定：`已验证` = 本仓库有回读证据（写在证据列）；`未验证` = wiki/推断，**用之前必须先测一次**。
> 全部数值要么带证据，要么标 `未验证`；不要凭印象补。

## 1. 世界机制规则

| 规则 | 状态 | 证据 |
|---|---|---|
| 当前世界 4200×1200（小世界），地表 y≈300，出生点 x≈2100 | 已验证 | `state` → `width/height`；出生点 (2099.5,303.7) |
| `Main.tile` 只在玩家附近已加载区有效（约 ±100 格），远处读回 air/`-1` | 已验证 | 远处 `tile` 恒 air；`scan` 半径上限 48 |
| 桥跑在客户端 `netMode=1`（host & play 的客户端侧），方块变更由服务端广播 | 已验证 | `place` 后立刻 `tile` 偶尔仍是旧值，等 300~1500ms 才稳定 |
| 死亡 → 满血在出生点复活，**物品不丢** | 已验证 | 多次死亡前后 `inventory` 一致 |
| 昼夜影响刷怪；夜里基地附近也会刷恶魔眼/僵尸 | 已验证 | 夜间 `npc r=40` 持续有 hostile |
| Journey 模式可研究/复制：`research` 到 100/100 后 `duplicate` 无限取 | 已验证 | 石块 100/100 → `duplicate` +900/次 |
| 生物群系可由 `state.player.zones` 判定（腐化/猩红/丛林/雪原/沙漠/沙滩/地牢/蘑菇/陨石/神圣/地狱/岩石层/泥土层/天空/地表） | 已验证 | `state` 的 `zones` 字段 |
| 小世界里腐化/丛林一般离出生点 1000~1500 格 | 未验证 | 需沿地表跑一遍记 `zones` 变化 |
| 世界存档：`save` 命令目前会 NRE（`Main.SaveWorld`），不要依赖它 | 已验证（bug） | 调用直接异常；退出游戏时游戏自己会存 |

## 2. 方块与物块属性规则

### 2.1 编号两类，别混

| 概念 | 区间 | 谁在用 |
|---|---|---|
| **物品 ID**（inventory 里的 stack） | `ItemID` | `craft {item}`、`equip {item}`、`buy/sell`、`give`（已删） |
| **方块 ID**（地图上的 tile） | `TileID` | `place {type}`、`fill {type}`、`find {type}`、`scan` 返回值 |
| **墙 ID**（背景墙） | `WallID` | `tile` 的 `wall` 字段；`wall {x,y,slot}` 贴墙 |

已核对的对照：石头 物品 3 → 方块 1；木材 物品 9 → 方块 30；土块 物品 2 → 方块 0。

### 2.2 常用方块 ID（都实测过）

| 方块 | ID | 备注 |
|---|---|---|
| 土 / 石 / 木材 | 0 / 1 / 30 | 建造主力；`fill` 常用 1 |
| 火把 | 4 | 光源；房屋判定也算 |
| 关门 / 开门 | 10 / 11 | 占 3 格高，锚点=**底部格** |
| 桌子 / 椅子 / 工作台 | 14 / 15 / 18 | 房屋的"平坦面 + 舒适物" |
| 平台 | 19 | **不算封闭**，只能当战斗场地 |
| 恶魔祭坛 | 26 | 腐化/猩红地下，召唤克苏鲁之眼用 |
| 铁矿 / 银矿 / 金矿 | 203 / 204? / 205? | 203 实测是铁矿；银/金 ID 用 `find` 前先 `api` 核对（未验证） |
| 绳子 | 213 | 攀爬用，见 §2.4 |
| 墓碑 | 85 | 会挡住判定视线，清理掉 |
| 熔炉 | 17 | 3×2，anchor=(1,1)，瞄 (2081,303) 占 (2080..2082,302..303) |

### 2.3 硬度与挖掘时间

- 铁镐挖丛林草 / 冰雪 / 石头约 **1.2~1.3 秒** → `mine` 的 `ms` 默认 1300；给 900 会"返回成功但方块不动"。`已验证`
- 挖一格前先看 `tile`：`hasTile:false` 就没必要挥镐（避免空挥 1.3 秒）。

### 2.4 液体、绳子、斜坡

| 规则 | 状态 | 说明 |
|---|---|---|
| 液体分薄水层（`liquid` 122~198，可趟）与满格/水腔（≥240，会溺水） | 已验证 | 破土前探脚下 3 行两列的 `liquid` |
| 水**不能被方块挤出**：往水里放方块 9 次全失败 | 已验证 | 无支撑 + 液体格拒绝放置 |
| 绳子只有角色中心对齐到绳列中心（`col+0.5`）才攀爬 | 已验证 | `climb` 前先对齐 x；偏一格就爬不动 |
| 斜坡（`slope` 1~5）/ 半砖会改变站立高度 | 已验证 | 放置时容易"放上去但站不住" |
| 平台是 `solidTop`，能站不能封 | 已验证 | 房屋屋顶用平台必失败 |

## 3. NPC 入住 / 生成规则

### 3.1 房屋有效的条件（原版规则）

| 条件 | 阈值 |
|---|---|
| 内部空腔格数 | **60 ~ 7500**（旧的 750 上限是错的，原版是 7500） |
| 四周封闭 | 实体方块或门；**任何一格漏（含平台、门上方空 2 格）都不合法** |
| 背墙 | 内部每格 `wall > 0` |
| 地板 / 天花板 / 左右墙 | 连续实心，不能断 |
| 家具 | 至少 1 个**平坦面**（桌/工作台/梳妆台）+ 1 个**舒适物**（椅/凳/王座） |
| 光源 | 至少 1 个（火把/蜡烛/吊灯/营火…） |
| 环境 | 不能是腐化/猩红/地牢/神圣（`state.player.zones` 可判） |

### 3.2 我们的判定链路（重要，别再踩）

| 事实 | 状态 | 证据 |
|---|---|---|
| `WorldGen.StartRoomCheck/CheckRoom/ScoreRoom` 在本环境**不可用**：同一间合法房报 `HoleInWallIsTooBig` | 已验证 | 合法房（自算 74 格封闭）→ 引擎 `tiles=17, box=[2102..2112]×[297..301], ceilings=11` |
| 引擎的 `numRoomTiles` 随种子乱变（0/3/13/17/27），`box` 永远往西、北漏到固定坐标 | 已验证 | 三个种子 3 / 27 / 11 |
| `WorldGen.moveRoom` 因此静默失败：`moved=false, reason=None`，NPC 的 `homeless` 不变 | 已验证 | `homeroom {x:2112,y:301,who:1}` |
| **唯一可信判据是自写 `housediag {x,y}`**（独立洪水填充 + 逐条核对 3.1 的规则，只读） | 已验证 | 合法房返回 `tiles=74, enclosed=true, walled=74/74, floor/ceil/left/right=1.00, light=2, comfort=2, flat=2, missing=[], valid=true` |
| 门装上后 `doors=3`（占 3 格），木门物品真的少 1 | 已验证 | 2103 的 301/302/303 = type 10；背包 4→3 |

### 3.3 NPC 行为

- 无家（`homeless=true`）的商人**照样能买东西**，只是会到处乱走、掉进坑里。`已验证`
- 城镇 NPC 会自己开门走进屋；**我们驱动的角色不会**（速度式移动不触发原版开门）→ 要过就挖掉再放回。`已验证`
- NPC 入住还需要前置条件（例如商人要 50 银币在身上/背包）→ `未验证`
- 幸福度影响价格，需要附近邻居/喜欢的环境 → `未验证`（本档尚未测过）

| 城镇 NPC 压制附近刷怪：3 个 NPC 时约 **250 格**内基本不刷 | 已验证 | 基地附近要走到 ~290 格才稳定遇怪 |

## 8. 游戏内判定标准速查（阈值表）

| 判定 | 阈值 | 命令/字段 |
|---|---|---|
| 房屋有效 | 见 §3.1；用 `housediag` | `housediag {x,y}` |
| 瞄准距离（挖/放） | ≤ **7 格** | 报错："够不到：离这一格超过 7 格" |
| 攻击半径 | `attack.r` 是硬半径，实用 12~22 | `attack {x,y,r}` |
| 交战距离（决策用） | 只打 **8 格内** | 16 格全打会让赶路变成 0 推进 |
| 对话 / 商店 | < 11 格 / < 12 格 | `talk` / `shop` |
| 合成站位 | 工位 **~1 格**内（宽松到 7 格内部分可用） | `craft` |
| 拾取 | 掉落在脚边 ~4 格内；**背包满则静默失败** | `grab`、`inventory` |
| 溺水 | 头入水约 10 秒开始掉血 | `state.player.wet/breath` |
| 坠落伤害 | 落 >25 格开始受伤 | `state.player.fallDist`（有则为准） |
| 背包 | 主背包 50 格 | `inventory` → `main_slots_used` |
| 世界存档 | `save` 目前坏 | 见 §1 |
