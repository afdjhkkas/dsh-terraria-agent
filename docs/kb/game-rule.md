# 游戏规则知识库（game_rule）

## 1. 房屋判定规则

- **有效房屋必须封闭**：四周由实心前景方块围合；边界上出现连续空缺（缺口过大）即判失败。
- **内部每格都要有背景墙**：缺墙的格子会让整间房失效；墙可以是任意材质的墙。
- 必备组件，缺一不可：
  1. **有效光源**（火把、灯、蜡烛、篝火等）；
  2. **一件平面放置物**（桌、工作台、梳妆台、书架等）；
  3. **一件坐具**（椅、床、马桶、长椅等）；
  4. **一个入口**（门、平台、活板门）。
- 内部空间有**下限**（约 60 格可站立面积）也有上限；太大同样不算有效房。
- **一个封闭空间只算一间房**；想住两个 NPC，必须用墙/门隔成两间。
- 房屋范围内**不能有腐化/猩红方块**，有几格就会判失败；神圣方块不阻止入住。
- 屋内**大量岩浆、持续流动的水、成片空洞**会导致判定失败。
- 判定与**地下深度、自然光、房间形状、材质贵重程度都无关**——只看封闭、墙、家具、光源、门。

## 2. NPC 入住与生成规则

- 入住前提三条同时满足：**存在有效空房** + **该 NPC 的解锁条件达成** + **当前没有入侵事件**。
  （例：商人需要玩家身上持有一定数量的银币，并且有一间空房。）
- 房间封闭不全、缺墙、缺光源、开口过大 → 不会入住。
- **一位 NPC 占一间房**，不会与他人合住；房间被破坏后 NPC 会离开。
- **环境偏好**：部分 NPC 对生物群系/高度有要求（例：蘑菇人只住蘑菇地；某些 NPC 偏好地表或地下）。
- **幸福度**按「独居与否 + 邻居是否喜欢 + 所在生物群系 + 拥挤程度」计算，直接影响售价与传送价格；
  不满意会明显涨价。
- **高刷怪区、持续战斗区、地形杂乱区**会降低入住意愿（就近怪物多时容易被反复打断）。
- **入侵/事件期间不会搬入**；事件结束后才恢复。
- NPC 一旦入住，会自己开门、走动、在附近游荡；夜间会回房。

## 3. 怪物刷新规则

- 只在**屏幕外一定距离**、**没有人工背景墙**、**可站立**的位置生成。
- **玩家放置的背景墙**会让该格无法刷怪（俗称"安全墙"），这是最可靠的防刷怪手段。
- **光源**不直接消灭已存在的怪，但会显著降低地表刷怪；大量照明能压住普通怪刷新。
- 刷怪权重随**深度、生物群系、昼夜、天气**变化；地表与地下是两套刷怪池。
- 附近有**城镇 NPC** 时刷怪率下降（城镇安全区）。
- **水蜡烛、战斗药水**提高刷怪；**和平蜡烛**降低刷怪。
- **事件**（血月、日食、哥布林入侵、史莱姆雨等）会替换或叠加普通刷怪表。
- 不同生物群系刷各自专属怪（腐化/猩红/丛林/地牢/雪原/沙漠/地狱各有不同表）。

## 4. 物块与地形规则

- **镐力门槛**：土/木/沙/雪无门槛；石类需要一定镐力；黑曜石、地牢砖、陨石等需要更高镐力；
  狱石需要地狱级镐或炸药。
- **锤子决定外形**：斜面、半砖、转角**只有锤子能改**；部分方块不可形变。
- **沙、雪泥、砂砾受重力下落**；水与岩浆会流动，可以用方块阻断，但**无法把水"挤走"**。
- **前景方块与背景墙是两套独立判定**：拆前景不影响墙，拆墙不影响方块。
- **平台可穿行**（下键下落）；**门需要交互打开**，靠移动不会自动开门。
- **舞台/平台、玻璃等不是封闭方块**：用它们做屋顶或外墙，房屋判定会失败。
- 树木、仙人掌、蘑菇、藤蔓属于植被，用斧头/镐清理的规则不同。

## 5. 环境扩散规则

- **腐化 / 猩红 / 神圣**会通过草、藤蔓、石块互相转化扩散，也会感染沙、冰等。
- **阻断材料**：黏土、灰烬、木材、地牢砖以及各类"不可侵蚀"方块不会被转化。
- **连续无缝的阻断层**能长期挡住蔓延；零星几块挡不住。
- **向日葵**能阻止地表草被转化（范围有限）。
- 困难模式后扩散速度显著加快，并会生成新的感染带。
- 净化手段：净化粉、圣水、环境改造枪，按区域清除。

## 6. 世界全局机制

- **一天 = 24 分钟**（白天 15 分、夜晚 9 分）；夜间刷怪更凶，部分怪只在夜间出现。
- **天气**：雨、雪、沙尘暴；会加强部分刷怪，也影响部分 NPC/生物出现。
- **事件**：血月、日食、史莱姆雨、哥布林入侵、海盗入侵、南瓜月/霜月、四柱等，各有触发与结束条件。
- **Boss 召唤**多数依赖：祭坛（腐化/猩红）、合成召唤物、特定地点/时间、或满足击杀前置。
- **击杀顺序影响世界状态**：例如击败血肉之墙后进入困难模式，矿物与刷怪全面升级。
- **死亡**：普通难度不掉落物品，重生点默认是出生点（可被床改变）。
- 世界生成是**分层的**：天空 → 地表 → 地下 → 洞穴 → 地狱；每层有各自的方块、生物与矿物。

## 7. 判定速查（问"算不算"时先看这里）

| 问题 | 判定 |
|---|---|
| 房屋是否有效 | 封闭 + 满墙 + 光源 + 平面物 + 坐具 + 入口 + 无污染 + 面积达标 |
| 为什么 NPC 不入住 | 房间不合格 / 解锁条件未达成 / 正在事件中 / 已有 NPC 占用 |
| 会不会刷怪 | 有背景墙 / 有城镇 NPC / 照明充足 → 不刷或很少刷 |
| 这个方块能不能挖 | 当前镐力 ≥ 方块要求 |
| 这个位置能不能放 | 有相邻支撑，或该物品允许悬空 |
| 水能不能被方块挤出去 | 不能；只能用方块阻断流向或做排水结构 |
| 污染会不会继续扩散 | 有没有连续的无缝阻断层；困难模式会加快 |
