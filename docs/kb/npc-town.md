# NPC 与城镇知识库（npc_town）

> **只写通用机制**：入住条件、幸福度算法、价格规则——与具体世界无关。
> 某一局里"哪个 NPC 已经住进来了""它们现在住哪"属于任务状态，不进库。

---

## 1. NPC 入住的两个必要条件

一个 NPC 要住进来，必须**同时**满足：

1. **有一个空的"有效房屋"**（房屋判定标准见 `game-rule.md`）；
2. **该 NPC 的出现条件已经满足**（见 §2 的表）。

- 每个 NPC 独占一间房：一间房里塞两个 NPC 是不可能的，即使房子很大。
- 玩家自己住的房子不算数——判定只认"有没有符合标准的封闭房间 + 门/平台 + 光源 + 家具 + 背景墙"。
- 房子被破坏（墙被挖掉一大段、门被拆、家具被拿走）后，NPC 会**失去归属**并在夜里被怪物攻击，
  白天会一直站着抱怨；重新修好后会自动回来。
- NPC 死亡不是永久的：会在一段时间后重新出现（需要原有房屋仍在）。

## 2. 常见 NPC 的出现条件

触发条件都是"**玩家的行为达到某个状态**"，不是靠时间等待：

| NPC | 出现条件 |
|---|---|
| 向导 | 世界开始时就在 |
| 商人 | 玩家持有的钱币达到一定数量，且有房 |
| 护士 | 玩家生命上限提高到某个值（用过生命水晶），且有房 |
| 军火商 | 玩家背包里出现过枪械或子弹，且有房 |
| 爆破专家 | 玩家背包里有爆炸物，且有房 |
| 染料商 | 玩家背包里有染料/染料原料，且有房 |
| 树妖 | 打败过任意一个首领之后 |
| 渔夫 | 在海洋边找到正在睡觉的渔夫并对话 |
| 哥布林工匠 | 哥布林入侵事件之后，在地下找到被绑的工匠并对话 |
| 电工妹 | 在地牢里找到被绑的电工并对话（需先打败骷髅王） |
| 巫师 | 在洞穴层找到被绑的巫师并对话 |
| 松露人 | 在**地表以上的发光蘑菇地**里建好房 |
| 蒸汽朋克 | 打败任意一个机械首领之后 |
| 机器人 | 打败世纪之花之后 |
| 税收官 | 困难模式后在地狱找到被折磨的灵魂并对话 |
| 派对女孩 | 随机到访（每天有一定概率），有房才留下来 |
| 旅商 | 随机到访（隔一段时间来一次），停留一天左右就走，不需要房 |
| 骷髅商人 | 随机出现在洞穴层，不需要房 |

- "随机到访"的 NPC 不占房屋名额，但**有房才能留下来的那类**必须备房。
- 想让某个 NPC 来，就去满足它的条件，然后**备一间空房**——两件事都做到才会出现。

## 3. 幸福度：价格是怎么算的

幸福度是**三个因素相加**，只影响三件事：**售价、传送价格、能否买到传送水晶**。

| 因素 | 加分情形 | 减分情形 |
|---|---|---|
| 生物群系 | 住在这个 NPC **喜欢**的群系 | 住在它**讨厌**的群系 |
| 邻居 | 附近住着它**喜欢**的 NPC | 附近住着它**讨厌**的 NPC |
| 拥挤 | 独居（附近没别的 NPC） | 附近挤了太多 NPC |

- "附近"是一个**有限的格数半径**（不是整个屏幕）：太远不算邻居，太密算拥挤。
- 因此最优布局是**成对独居**：把互相喜欢的两个 NPC 放在同一个群系、彼此相邻、远离其他 NPC。
- 幸福度只影响**这个 NPC 自己的**价格，不会影响别人的。
- NPC 会**主动说出**自己喜欢什么群系、喜欢谁——对话里就有，不用猜。

## 4. 传送水晶（Pylon）

- 每个生物群系各有一种传送水晶，**同一群系只能放一根**。
- 一根水晶要**正常工作**，需要该群系附近住着**足够数量的 NPC**（两个左右）；
  只有水晶没有 NPC，它不会被激活。
- 使用时必须在**另一根已激活的水晶附近**，才能在水晶之间互相传送。
- 因此"铺传送网"的正确顺序是：先在该群系安顿好 NPC → 水晶被激活 → 再去下一个群系。

## 5. 交易与商店

- 商店货架由**NPC 自身 + 时间/月相/事件/幸福度**共同决定，同一件东西价格会变。
- **买之前先读价格**，不要凭印象；幸福度差的时候差价很明显。
- 卖出价通常是物品价值的一部分，幸福度高时卖得更多。
- 部分 NPC 只在特定条件下卖特定货（例如困难模式后、某个首领之后、血月之夜）。

### 渔夫任务（每日）

- 渔夫每天给**一个**任务：指定一种"任务鱼"，只能在**特定群系/深度**钓到；任务鱼**不能堆叠**，一天一条。
- 交付：拿着鱼靠近渔夫对话 → 交任务 → 领奖励（钱币/渔具/饰品）。
- 读任务用 `quest`（实测返回 `{kind:"daily_fish", index, itemId, itemName}`），交付走 `talk`；任务每天刷新，过期的任务鱼作废。

## 6. 速查

| 问题 | 答案 |
|---|---|
| NPC 为什么不来 | 没有空的有效房屋，或它的出现条件没满足（两件事都要） |
| NPC 为什么不住我建的房 | 房屋不合法（见 `game-rule.md` 的判定），或被别的 NPC 占了 |
| 房价为什么贵 | 幸福度低：群系不对 / 邻居不对 / 太挤 |
| 怎么让价格最低 | 成对独居 + 各自喜欢的群系 + 互相是喜欢的邻居 |
| 传送水晶为什么不能用 | 该群系 NPC 数量不够，或另一端没有已激活的水晶 |
| NPC 死了怎么办 | 房屋还在就会重来；房屋没了就会一直无家可归 |
## 住房墙：人工墙才算，自然墙一堵都不算

- NPC 入住判定的"墙"只认**玩家摆放的可入住墙**：原版用 `Main.wallHouse[wallType]` 标记，
  木墙、石砖墙等为真；**泥土墙、岩石原生墙等地图自带墙为假**。
- 因此"这格有没有墙"（`wall != 0`）不能当判据——洞穴里到处是墙，仍然一堵都不算。
- 工具里读 `tile.wallHouse` 才是权威答案；铺墙时传的是**墙 id**（例如木墙 4），
  不是物品 id（木墙物品 93）。
- 已经把自然墙铺进房子时：先用锤子锤掉，再铺人工墙，不要在上面叠。
