# 装备进阶路线知识库（gear_route）

> **只写通用机制**：升级阶梯、门槛、选择依据——与具体世界无关。
> "我现在有几块铁"属于状态，不进库；想知道某件装备的具体数值用 `api` / `tiledata` 查。

---

## 1. 挖矿的镐力门槛（决定你能去哪一层）

- 每种矿石/方块都有一个**最低镐力要求**，镐力不够就完全挖不动（不是变慢，是无效）。
- 所以"升级路线"的第一约束不是钱，是**镐力**：镐力决定你能进哪个矿带，矿带决定你的下一套装。
- 想知道某个方块需要多少镐力、某把镐有多少镐力，用 `tiledata` / `api` 查，不要凭印象。
- 锤子和斧子有各自的"锤力/斧力"，用于拆墙与砍树；它们**不能**替代镐子挖矿。

## 2. 矿石阶梯（前困难模式 → 困难模式）

**前困难模式**（按镐力逐级解锁）：

```
铜/锡 → 铁/铅 → 银/钨 → 金/铂金 → 陨石（需先触发陨石落地）
      → 魔矿（腐化）或 猩红矿（猩红）→ 狱石（地狱，最高一档前困难矿）
```

**困难模式**（打进血肉墙之后）：

```
钴/钯 → 秘银/山铜 → 精金/钛金 → 神圣锭 → 叶绿 → 四柱材料 → 月之领主材料
```

- 括号里的两套是**世界二选一**：同一个世界里要么出铜锡这一套，要么出另一套，
  但**同一档的两者强度接近**，不用纠结。
- 每进一档，先做**镐子**再考虑护甲——镐子决定下一档能不能挖。
- 困难模式新矿不会自动出现：需要用**锤类工具砸碎祭坛**来刷新矿脉（见 `progression-boss.md`）。

## 3. 护甲：三件套 + 职业分支

- 每档矿石能做**头盔 / 胸甲 / 护腿**三件，穿齐有**套装效果**（额外加成）；
  零散穿不如穿齐低一档——套装加成通常比单件数值更值。
- 前困难模式的护甲基本是**通用型**（防御 + 少量多项加成）。
- **困难模式开始分职业**：每档矿石通常有三种版本，分别强化近战 / 远程 / 魔法 / 召唤。
  分职业后要**选定一条线**穿齐，混穿会两头不讨好。
- 防御是**减法**（见 `combat-math.md`）：堆防御对低伤害小怪极有效，对高伤害首领收益递减。
  所以打首领时，**机动性（翅膀/靴子）常常比多几点防御更保命**。

## 4. 武器：四条职业线的早期选择

| 职业 | 早期能拿到什么 | 特点 |
|---|---|---|
| 近战 | 木剑 → 铜/铁/银/金剑；回旋镖、链球 | 不耗弹药，靠贴脸，需要防御支撑 |
| 远程 | 木弓 → 各级弓 + 箭；枪械（需先有枪） | 有弹药成本，安全距离输出 |
| 魔法 | 宝石法杖、书类、部分掉落法杖 | 耗魔力，靠魔力药水与回蓝饰品 |
| 召唤 | 早期召唤杖（宝箱/低级怪）+ 哨兵 | 可以边跑边打，本体仍要自己躲 |

- 前期不必"专精"：哪条线先拿到好东西就走哪条；**困难模式分职业后**再定型。
- 判断一把武器好不好，看 **单发伤害 × 每秒命中次数 × 命中率**，不要只看面板单发数字。
- **穿透**武器清群强、打单体首领可能因为无敌帧反而更弱（见 `combat-math.md`）。

## 5. 饰品与机动性（真正决定生死的一环）

- **机动性三件套**：二段跳（云朵/暴雪/沙暴瓶一类的瓶子）→ 冲刺/加速靴 → 翅膀。
  这三样凑齐后，"打不过就跑"才真的成立。
- **免摔**（马蹄铁一类）在探索竖井和洞穴时价值极高。
- **职业饰品**（加某一类伤害/暴击）要在确定职业线之后再堆。
- 饰品的**词条**可以重铸改造（见 §6），同一条饰品换个词条等于换一件装备。

## 6. 词条（前缀）与重铸

- 武器/饰品/工具带**前缀**，前缀改变伤害、暴击、攻速、击退、防御等，分优劣档。
- 重铸 NPC（哥布林工匠）可以**随机重换**前缀，消耗钱币，结果随机——可能更好也可能更差。
- 一般策略：先保证"能用的装备"，有余钱再赌词条；**不要在还缺装备时把钱全砸进重铸**。

## 7. 增益药水：性价比最高的一步

- 打首领前喝药是**成本最低的强度提升**，常见方向：加防御、加伤害、加攻速/移速、加回血、
  加魔力回复、夜视、免摔、水下呼吸。
- 药水**互相叠加**（不同种类），同种不叠加。
- 药水要靠钓鱼/采集/掉落攒材料，所以"打之前先看包里有什么药"应该成为固定动作。

## 8. 速查

| 问题 | 答案 |
|---|---|
| 下一步该做什么装备 | 先看镐力能挖到哪一档 → 做那一档的镐 → 再补该档护甲三件 |
| 挖不动某个矿 | 镐力不够，先升级镐子（用 `tiledata` 确认门槛） |
| 护甲要不要穿齐 | 要，套装效果通常比零散高级件更值 |
| 打首领总死 | 先补机动性（二段跳/靴子/翅膀）+ 药水，再谈防御 |
| 钱该花在重铸还是装备 | 缺装备时先买/做装备，富裕了再赌词条 |
| 武器怎么比好坏 | 单发伤害 × 每秒命中 × 命中率；再看穿透是否被无敌帧吃掉 |
