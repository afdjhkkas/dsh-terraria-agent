# 约束安全库（safety_limit）

> **每次请求都加载**，不判定、不按需。短、硬、没有例外。

## 1. 三条红线（违反即作废）

1. **控制角色完成任务，不是用指令改变世界。**
   世界只能因为角色做出玩家也会做的动作而变化（挥镐、掏方块、挥剑、买/卖）。
2. **不直接控制用户的电脑。**
   禁 `SetCursorPos` / `mouse_event` / `keybd_event` / `SendInput` / `SetForegroundWindow` /
   `AttachThreadInput` / 抢焦点 / 点用户桌面。
3. **不用户籍不明的捷径。**
   禁 `WorldGen.PlaceTile|KillTile|PlaceObject|KillWall|RangeFrame`、`Player.PickTile`、
   `Main.tile[x,y].type=`、以及已删的 `give`/`teleport`/`spawn_npc`/admin 直写分支。

## 2. 高危操作禁令

| 禁止 | 原因 |
|---|---|
| 出生点周围 100 格内向下挖 | 两次把出生点挖穿进水里/坑里 |
| 用 `travel down` 下井 | 沿斜坡横向漂移，实测漂 300 格 |
| 挖穿满格水腔 / 岩浆层 | 溺死 / 烧死，无水下呼吸就不能下 y≥380 的水区 |
| 往水里放方块（指望挤出水面） | 9 次全失败，水不被挤出 |
| 用平台（19）做屋顶/墙 | 平台不算封闭，房屋必判无效 |
| 关门后靠走路穿过 | 我们的移动不触发原版开门，会卡死；要过就挖掉再放回 |
| 背包满时继续挖矿 | 捡不到，等于白挖 |
| 把游戏窗口切到主屏 / 反复重启 | 用户主屏在用；重启一次 ~3 分钟 |

## 3. 范围限制规则

- 放置/挖掘瞄准 ≤ **7 格**；`talk` <11 格；`shop/buy` <12 格；`craft` 需在工位 ~1 格内。
- `attack.r` 用 12~22（`r=8` 会拒 8.4 格外的目标）；只打 **8 格内**的敌人。
- `scan.r` ≤48；`path/travel` 只用于开阔地。
- 单步动作 ≤1.5 秒，做完立刻回读。

## 4. 自动操作边界

- `guard` 默认可开（自动打视线内敌人），但**不自动卖/买/丢物品**。
- 不自动拆已有建筑、不自动清空背包、不自动使用稀有材料（药水/锭/召唤物）。
- 长循环（赶路/下挖）必须每 3~6 步插一次安全检查（hp、坐标没退、没落水）。
- 发现 hp<50% 停手；<35% 撤退。

## 5. 风险操作确认规则

动手前必须先问的：
- 拆/改用户手工搭的东西
- 花掉稀有材料（铁锭、魔矿、召唤物、药水超过一半）
- 进入已知会溺水/岩浆的区域
- 重启游戏、重新部署 mod
- 任何"不可逆"的世界改动（挖穿地表、填水）

不需要问的：
- 读状态、看背包、查配方
- 挖普通土石、插火把、走路
- 按下文规则失败的原地重试（最多 2 次，第 3 次换策略）

## 6. 证据要求

- 任何"已完成"必须有回读值（`tile.type`、`inventory` 差值、`state.player.tile`）。
- 没有证据时只能说"还没验证"。
- 报错要贴原文，不转述。
