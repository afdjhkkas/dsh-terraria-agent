# 全局安全约束知识库（safety_limit）

> **兜底库：每次请求都加载。** 只写与地图无关的通用限制与自检规则。
> 这里不写"哪一次因为什么死了"——那些属于调试记录，不属于规则。

---

## 1. 禁止行为清单

| 禁止 | 原因 |
|---|---|
| **大面积铺设岩浆、流动水体** | 会烧毁/冲掉自己的建筑与掉落物，且不可逆 |
| **主动批量放置腐化/猩红/神圣方块** | 会污染周围地形，扩散后极难清理 |
| **擅自大规模拆除玩家建好的建筑** | 用户的建筑是资产，拆了要重建 |
| **破坏玩家保留的重要设施**（床、祭坛、箱子、传送器） | 不可逆，且可能卡住进度 |
| **建造会把角色卡死、无法通行的畸形结构** | 自己也会被困住，救援成本高 |
| **建造极易导致坠落死亡的高危悬空结构** | 一次失足就掉装备、掉进度 |
| **在出生点/城镇正下方垂直下挖** | 会把出生点挖成水坑或怪洞，死了反复掉进去 |
| **挖穿满格水体、岩浆腔** | 瞬间灌满通道，几乎没有救援窗口 |
| **在怪群里贪挖** | 挖矿时无法有效还击，血线掉得比想象快 |
| **背包满还继续长时间作业** | 掉落物捡不到，等于白干 |
| **拿角色去试"能不能扛住"** | 死亡代价远大于收益 |
| **未确认退路就进危险地形**（深水、岩浆边、高空） | 一次失误就是重置进度 |

## 2. 操作范围限制

- **单次批量地形改造 / 建造**默认有上限（约 200 格）；超出的工程**先报方案再开工**。
- **单段移动/挖掘动作要短**：一小段一停，做完立刻确认位置与血量。
- **交互距离**：站到能碰到目标的距离再动手，不隔空操作。
- **同时只做一件事**：不边走边挖、不边挖边放。
- **主背包留出余量**：快满时先存箱子，再继续。
- **单次合成/批量制造**先算材料总量，别把关键材料一次用光。
- **写操作（放置/挖掘/拆）每次都要回读确认**；没确认就当没发生。

## 3. 自检修正规则

- **建造自检**：结构有缺口 → 补；缺光源 → 加；缺墙 → 补墙；缺门 → 装门；缺桌椅 → 补齐。
- **通路自检**：完工前自己走一遍，卡住就改。
- **危险自检**：脚下有没有水/岩浆？头顶会不会塌？退路还在吗？
- **血量自检**：低于安全线就停手回血；不要在低血时开新工程。
- **物品自检**：动手前确认背包里有该用的东西，且真的切到了手上。
- **预判禁止项**：这一步会不会碰到上面任何一条禁令？会就先停下来问。
- **发现自己在"重复同一个失败动作"** → 立刻停，换策略或上报，不要靠次数硬碰。

## 别在成品建筑旁边用"带挖掘的寻路"

带挖掘的自动寻路只认"能不能过去"，**不认"这是我自己刚盖好的房子"**：
它会直接从墙里打通一条最短路，把刚通过验收的房间挖出洞，房屋判定随即作废（`enclosed` 变假、空间统计跑到 9000 格上限）。

- 进出自建房走**门**，不要用带挖掘的寻路。
- 万一把墙挖漏了：先把人挪到墙外侧一格，再自下而上把墙补回去（每格都要回读），最后重跑一次房屋判定。
