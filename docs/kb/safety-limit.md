# 约束安全库（safety_limit）

> **每次请求都加载**，不判定、不按需。短、硬、没有例外。
> 每条禁令后面都跟着本档真实踩过的证据；没有证据的条目不写进禁令。

---

## 1. 高危操作禁令（红线，违反即作废）

1. **控制角色完成任务，不是用指令改变世界。**
   世界只能因为角色做了玩家也会做的动作而变化（挥镐、掏方块、挥剑、买卖）。
2. **不直接控制用户的电脑。**
   禁 `SetCursorPos` / `mouse_event` / `keybd_event` / `SendInput` / `SetForegroundWindow` /
   `AttachThreadInput` / 抢焦点 / 点用户桌面；插件的 `tr_key`/`tr_walk`/`tr_mouse` 已删除。
3. **不走作弊捷径。**
   禁 `WorldGen.PlaceTile|KillTile|PlaceObject|KillWall|RangeFrame`、`Player.PickTile`、
   `Main.tile[x,y].type = ...`、admin 直写；`give`/`teleport`/`spawn_npc` 已移除，不要加回。

| 禁止动作 | 本档证据（代价） |
|---|---|
| 出生点 100 格内向下挖 | 两次把出生点挖穿进水里：魔镜回来从 y=360 掉到 402 落进积水，反复淹死 |
| 用 `travel down` 下井 | 沿斜坡横向漂移：下 20 格横漂 **300 格** |
| 挖穿满格水腔 / 岩浆 | 一次 `travel right` 在 y≈408 隧道里淹死；竖井打到 y=466 见岩浆 |
| 往水里放方块（指望挤出水） | 9 次全部失败（无支撑 + 液体格拒绝放置） |
| 用平台（19）做屋顶/墙 | 平台不算封闭，房屋判定必失败 |
| 关门后靠走路穿过 | 速度式移动不触发原版开门，卡死在门里 |
| 背包满（50/50）继续挖 | 掉落物全部捡不到，等于白挖 30+ 格 |
| 把游戏窗口切到主屏 / 反复重启 | 主屏在用；重启一次约 3 分钟，还要重新进世界 |
| 拿 `tr_observe` 的"缩放/偏移"去点鼠标 | 那是只读像素，坐标不可信（自己推算过，全错） |
| 站在出生点不动过夜 | 夜+雨实测 **24 秒**被打死 |

## 2. 范围限制规则

- 挖/放瞄准 **≤7 格**（实用 ≤4）；`talk` <11 格；`shop/buy/sell` <12 格；`craft` 工位 ~1 格；`chest` ≤6 格。
- `attack.r` 用 **12~22**（`r=8` 会拒 8.4 格外目标）；只主动打 **8 格内**。
- `scan.r ≤48`；`find` 只在已加载区（约 ±100 格）有效；`grab` 有效半径 **4 格**。
- 单步动作 **≤1.5 秒**，做完立刻回读。
- 主背包 50 格；`main_slots_used ≥45` 先清包。
- `fill` 单次 ≤30 格；`craft` `times` ≤20。

---

## 3. 自动操作边界

- `guard` 默认可开（只打视线内），但**不自动买/卖/丢物品**。
- 不自动拆已有建筑、不自动清空背包、不自动花稀有材料（锭/召唤物/药水）。
- 长循环（赶路 / 下挖 / 施工）必须每 **3~6 步**插一次安全检查：hp、坐标没退、没落水。
- hp <50% 停手，<35% 撤退，<25% `mirror` 回城。
- 不替用户做不可逆决定（"把这片区域全挖平"之类）——先报方案。
- 自动防守不等于自动送死：怪在墙后/水对面时**不许主动冲**。

---

## 4. 风险操作确认规则

**动手前必须先问**

- 拆/改用户手工搭的东西；
- 花掉稀有材料（铁锭、魔矿、召唤物，一次超过一半）；
- 进入已知会溺水/岩浆的区域；
- 重启游戏、重新部署 mod（会中断用户正在看的世界）；
- 任何不可逆的世界改动（挖穿地表、填水、平地形）；
- 写游戏状态（NPC 归属、研究进度）除非已获授权。

**不需要问**

- 读状态、看背包、查配方、查方块；
- 挖普通土石、插火把、走路；
- 按规则失败的原地重试（最多 2 次，第 3 次换策略）。

## 5. 证据要求

- 任何"已完成"必须有回读值：`tile.type`、`inventory` 差值、`state.player.tile`、`housediag.valid`。
- 没有证据只能说"还没验证"，不能说"应该好了"。
- 报错贴原文，不转述。
- 代码改动给 `文件:行号`（例如 `DshTerrariaBridge/Commands.cs` 的 `HouseDiag`），避免文档与实现漂移。
- 落水/落岩浆/死亡这类"结果很响"的事件，也要贴数值（hp 曲线、坐标变化），不要只说"失败了"。
