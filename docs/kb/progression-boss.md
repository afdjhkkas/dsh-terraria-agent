# 进程与首领知识库（progression_boss）

> **只写通用机制**：召唤条件、解锁顺序、必需前置——换任何世界都成立。
> 某一局"打到哪一步了"属于任务状态，记在任务记录里，不写进库。

---

## 1. 进程是骨牌：谁解锁谁

```
起始
 ├─ 生命水晶 → 生命上限 200 → 克苏鲁之眼可自然出现
 ├─ 打败克苏鲁之眼 → 掉落材料 → 做更好的武器/护甲
 ├─ 腐化：破暗影珠 / 猩红：破猩红之心 → 拿到陨石、枪、腐化/猩红装备
 ├─ 打败世界吞噬者（腐化）或克苏鲁之脑（猩红） → 陨石落地、可选装备
 ├─ 丛林找蜂巢 → 打败蜂王 → 蜂系装备
 ├─ 地牢门口打败骷髅王 → 地牢可进 → 金钥匙开箱 → 大量装备
 ├─ 地狱 → 向导巫毒娃娃丢岩浆 → 打败血肉墙 → 【进入困难模式】
 └─ 困难模式：机械三王 → 世纪之花 → 石巨人 → 四柱 → 月亮领主
```

- **困难模式一旦开启不可逆**：世界永久进入困难阶段，腐化/神圣开始加速扩散。
- 每一步的真正门槛通常是**装备与场地**，而不是"有没有钥匙"——所以卡住先看防御/血量/竞技场。

## 2. 前困难模式首领：怎么召唤

| 首领 | 召唤方式 | 前置/限制 |
|---|---|---|
| 史莱姆王 | 史莱姆王冠（凝胶 + 金/铂金冠 + 红宝石，祭坛合成）在任意处使用；或在"史莱姆雨"事件里自然登场 | 无硬性前置 |
| 克苏鲁之眼 | 可疑眼球（晶状体合成，祭坛）在**夜晚**使用 | 也可自然出现：生命够高、有城镇 NPC、夜里 |
| 世界吞噬者 | **腐化世界**：打碎 3 个暗影珠；或蠕虫诱饵（腐化材料在祭坛合成） | 必须在腐化之地 |
| 克苏鲁之脑 | **猩红世界**：打碎 3 个猩红之心；或血脊椎（猩红材料在祭坛合成） | 必须在猩红之地 |
| 蜂王 | 打碎地下丛林蜂巢里的**幼虫**；或蜂巢召唤物 | 需要先进地下丛林 |
| 骷髅王 | **夜晚**在地牢门口与老人对话并接受诅咒 | 白天对话会直接被秒；打败后地牢才安全 |
| 血肉墙 | 把**向导巫毒娃娃**丢进地狱岩浆（向导必须活着） | 打不过会拖走向导；必须在地狱 |

## 3. 困难模式首领：顺序与门槛

| 首领 | 召唤方式 | 门槛 |
|---|---|---|
| 机械三王（双子魔眼 / 毁灭者 / 机械骷髅王） | 对应的机械召唤物，**夜晚**使用 | 三个可以分开打，没有固定顺序 |
| 世纪之花 | 三个机械王全灭后，地下丛林出现"世纪之花球茎"，打碎它 | 必须先打完三王 |
| 石巨人 | 丛林神庙深处，用电池激活祭坛 | 必须先打败世纪之花（神庙门才开） |
| 猪龙鱼公爵 | 在海洋用**松露虫**当鱼饵钓鱼 | 松露虫只在地下发光蘑菇地抓 |
| 光之女皇 | 夜晚在神圣地表击杀"彩虹晶蝶" | 白天召唤会进入狂暴形态 |
| 月亮领主 | 打败四柱后自动出现；或用天界符召唤 | 需要先打败地牢门口的拜月教邪教徒触发四柱 |

## 4. 祭坛（恶魔/猩红祭坛）能干什么

- **合成**：所有"召唤物"" Boss 材料装备""困难模式锭"都要在祭坛旁合成。
- **破坏祭坛**（困难模式、用锤类工具）会在世界中**随机生成新矿脉**（钴/钯、秘银/山铜、精金/钛金），
  每破坏一个就多刷一批；破坏太多会加速腐化扩散。
- 祭坛本身**不可搬走**，只能就地用；所以"要做召唤物"必须走到腐化/猩红之地。
- 猩红世界用**猩红祭坛**，腐化世界用**恶魔祭坛**，功能等价。

## 5. 打首领前的通用准备（与具体首领无关）

- **场地**：一片平整、够长（能来回跑）、头顶有几层平台的空间；地面铺平避免卡住。
- **补给**：治疗药水、增加属性的药水、火把（夜晚/Boss 场地要亮）、返回手段（魔镜）。
- **退路**：血量掉到一半以下先撤，喝药再上；被追击时往平台上方跳。
- **不要在城镇里打**：会波及 NPC；也不要在自己唯一的房子旁边打。
- **Boss 战期间不要挖矿/建造**：分心会被连击。

## 6. 速查

| 问题 | 答案 |
|---|---|
| 现在该打谁 | 按 §1 的骨牌，第一个"前置齐了但还没打"的就是 |
| 打不过怎么办 | 先补防御/血量/药水，再修竞技场；不要硬碰 |
| 为什么召唤物用不了 | 时间不对（夜/昼）、地点不对（生物群系）、前置没达成 |
| 困难模式怎么进 | 地狱里把向导巫毒娃娃丢进岩浆并打败血肉墙 |
| 新矿怎么来 | 困难模式后用锤子砸祭坛，砸一个刷一批 |
| 地牢为什么进不去 | 骷髅王还没打（或没在夜里打） |
