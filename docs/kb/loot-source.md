# 物品来源知识库（loot_source）

> **只写通用机制**：哪类容器/来源能给哪类东西——与具体世界无关。
> 具体掉落概率以游戏内掉落表为准（`api` / `find` 可查），本库只写"去哪找、为什么要去"。

---

## 1. 自然容器（最早、最稳的装备来源）

| 容器 | 在哪 | 特点 |
|---|---|---|
| 木箱 / 木桶 | 地表、地下、洞穴 | 少钱、火把、消耗品，偶尔有早期武器 |
| 金箱 | 洞穴层、地下小屋深处 | 有**保底特殊物品**（钩爪、云朵瓶一类早期关键件） |
| 冰雪箱 | 雪原地下 | 冰雪主题装备 |
| 常春藤箱 | 地下丛林 | 丛林主题材料、部分武器 |
| 沙岩箱 | 沙漠地下 | 沙漠主题装备，含"远古"系列 |
| 水之箱 | 海洋底部 | 海洋主题装备、珊瑚 |
| 暗影箱 | 地狱废墟 | 需要**暗影钥匙**（地牢里找）才能开；含地狱级武器 |
| 地牢金箱 | 地牢 | 需要**金钥匙**（地牢里怪物/其他箱子掉）；含地牢专属武器与饰品 |

- 容器**不刷新**，找过就没有了；箱子里的东西与该世界种子绑定。
- 打破容器要**空手或任意工具**都行，但要有掉落物落地再捡（背包满会静默失败）。

## 2. 掉落规则

- 怪物掉落分：**必掉**（钱币、常见材料）、**概率掉**（装备，通常很低）、**首次掉落**（第一次击杀必给）。
- **旗帜/成就类**多为"击杀 N 只后必定解锁"，不是概率。
- 掉落**不会自动进背包**：要先落地，再让角色走过去捡（距离约 4 格内）。
- 提高掉落：**幸运**、部分药水、"战斗"类事件（血月/日食会换掉落表）。
- 死亡**不掉落背包**（本作默认不掉），所以"打不过先撤"成本很低。

## 3. 钓鱼与板条箱

- 任何水面都能钓（需要钓竿 + 鱼饵），**产物由水域的生物群系与深度决定**。
- 钓上来的**板条箱（木/铁/金）**打开后给矿锭、饰品、钱币——是**不用挖矿就拿到矿**的主要途径。
- 钓到"垃圾"也算进度：不同群系有专属鱼类与专属箱子。
- 特殊鱼饵用途：**松露虫**（发光蘑菇地抓）用来召唤猪龙鱼公爵。

## 4. 首领与事件掉落

- 首领的掉落分：**必掉材料**（用来做下一阶段装备）+ **概率掉专属装备**。
- **"首次击杀"与"重复击杀"掉落不同**：有些只给一次。
- 事件（哥布林入侵、海盗入侵、南瓜月、霜月）掉落**事件专属货币/材料**，用来在事件 NPC 处换装备。
- 打首领前先确认：**场地够大、药水够、退路有**——掉落再好，死了也拿不到。

## 5. NPC 商店

- 城镇 NPC 用**钱币**卖东西，货架随**时间/月相/事件/幸福度**变化。
- **幸福度**（独居 + 喜欢的邻居 + 喜欢的生物群系 + 不拥挤）会直接反映到**售价与传送价格**。
- 部分 NPC 有**解锁条件**（例如持有一定数量的钱、打败某个首领、进入困难模式）。
- 买之前先在商店界面**读价格**，不要凭印象——同一件东西在不同幸福度下差价很大。

## 6. 转化与回收（1.4 之后的新路径）

- **提取机**：把泥沙/雪泥/沙漠化石丢进去，随机产出矿石、宝石、钱币。
- **微光（Shimmer）**：一种特殊液体，把物品丢进去会**转化**成另一件（同系列降级/异变），
  也能让部分 NPC 变形；是"把废件换成有用件"的路子。
- **重铸**：把武器/饰品交给哥布林工匠重铸，随机换词条（消耗钱币）。
- **拆解**：部分物品能拆回材料（工作台类）。

## 7. 速查

| 问题 | 答案 |
|---|---|
| 早期装备去哪找 | 地下小屋的木箱/金箱，金箱有保底特殊件 |
| 不想挖矿怎么拿矿 | 钓鱼开板条箱；或用提取机处理泥沙 |
| 地牢/地狱的箱子打不开 | 分别需要金钥匙 / 暗影钥匙 |
| 东西为什么捡不起来 | 背包满 / 距离超过约 4 格 / 物品还在下落 |
| 想刷某件掉落 | 提高幸运 + 找对应群系与深度 + 夜间/事件换表 |
| 钱怎么来 | 卖掉落物给 NPC、开箱、事件货币；幸福度高卖得贵 |
