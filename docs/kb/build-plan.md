# 建造方案库（build_plan）

> 什么时候加载：要造东西 / 改造地形。
> 前提：一切以**真人物品流**施工 —— 方块靠 `place` 掏、靠 `mine` 挖、家具靠 `craft` 做再 `place` 放。
> 用户明确禁止"写个脚本一口气生成整栋房子"；本库只给**判据、尺寸、顺序、坑**。

---

## 1. 基础建筑标准模板

### 1.1 NPC 房（已验证的最小可用尺寸）

| 项 | 数值 | 说明 |
|---|---|---|
| 内部净空 | **15 宽 × 5 高 = 74 格**（下限 60） | 外框 17×7；太小不达标，太大浪费材料 |
| 墙/地板/天花板 | 实心方块（木 30 / 石 1 / 土 0） | **不能用平台 19**（不算封闭） |
| 背墙 | 内部**每格** `wall > 0` | 木墙/土墙都行；缺一格就会被判漏 |
| 门 | 1 扇 `ClosedDoor`（方块 10，占 3 格，锚点=**底部格**） | 门要装在可站的地板行上 |
| 家具 | 平坦面 ×1（桌 14 / 工作台 18）+ 舒适物 ×1（椅 15） | 放在同一条地板上 |
| 光源 | 火把 4 ×1~2 | 火把别挡住门口 |
| 判定 | `housediag {x,y}` → `valid:true`，`missing:[]` | 别用 `roomcheck`/`homeroom`（引擎判定坏，见 game-rule §3.2） |

**施工顺序（顺序错了会返工）**

1. `scan` 存一份现状（出问题能复原）。
2. 先定**地板行**，逐格确认实心（`tile` 回读，别信"应该放上了"）。
3. 砌左右墙 → 贴背墙（`wall`）→ 最后封天花板。
4. 天花板封之前别放家具（后放的方块会挡住先放的家具）。
5. 门最后装；装门前把门位挖成 3 格高、下方有实心地板。
6. `housediag` 复核；`valid:true` 再去（在允许的前提下）让 NPC 入住。

### 1.2 竖井（下行）

```
每下一格：
  1) mine 两列 floor(px-0.55) / floor(px+0.55)，y = py+2，ms=1500
  2) 等 ~1.5s（挥镐动画 + 服务端同步），角色自然下落一格
  3) 每 6~8 格插一根火把（先 find type:4 数已有）
  4) 落水检查：脚下两列 3 行，liquid ≥240 或连续 2 格水 → 停
```
- **禁止** `travel down`：沿斜坡横向漂移（实测 20 格下达漂 300 格）。
- 竖井底要留**横移空间**（≥3 格），否则到底后被卡住。
- 想再上来：只在绳子（213）铺好的井里 `climb up`；否则用 `mirror`。

### 1.3 横向通道 / 隧道

- 高度 **3 格**（角色 3 格高），宽度按用途；只挖 `dy=-2..0`。
- **不要挖脚下 `dy=+1`**：会越走越深（实测 80+ 格下沉）。
- 每 6~8 格火把；尽头用 `fill` 补回地板防掉落。

### 1.4 战斗平台（打 Boss）

- 多层水平平台（tile 19 平台，可上下穿），层间 **6~8 格**，宽 ≥60 格。
- 两端封方块挡怪；平台下方留 3 格高走道。
- 平台不能用来做 NPC 房。

## 4. 结构布局规范

- **出生点周围 100 格内不向下挖**（两次把出生点挖穿进水里；用户明确要求）。
- 工位与玩家常用站位保持 ≤7 格（放置/合成距离），合成最好 ~1 格。
- 竖井不要打在房屋正下方（漏水/漏怪/塌方）。
- 横向主通道放在地表下 2~3 格，避免挖穿草皮。
- 基地边缘要**砌护栏**：实测在 (2075,300..303) 补 4 格石头后，向左顶 1.4 秒位置锁死（y 不再从 303 掉到 466）。

## 5. 安全建造约束

```text
改造前：scan 一份现状
每一步：只放 1~3 格 → tile 回读 → 再放
每个阶段末：state 确认 (tile, life, wet, dead) 正常
```

- 任何"把角色围起来"的操作（补墙/封顶/贴背墙）之后**立刻确认还能动**（`state` 看坐标是否变化）。
- 不挖穿满格水腔/岩浆；不往水里放方块（挤不出去，9 次全失败）。
- 背包满时别大规模施工：挖出来的东西捡不到，等于白干。

## 6. 特殊环境建造

| 环境 | 要求 | 状态 |
|---|---|---|
| 水下 | 要么排水（目前**做不到**，水不能被方块挤出），要么水下呼吸（鱼鳃药水/海神贝壳） | 已验证"排水不可行" |
| 地狱（y≈466 见岩浆） | 需要抗火/黑曜石皮肤，落点必须垫实心；无安全垫不要下 | 未验证 |
| 空岛 | 需铺实体地板防坠落 + 长距离可达（翅膀/抓钩） | 未验证 |
| 雪原 | 低温只影响视觉（无冻伤机制），但地形陡、怪多；去过 5 次全死 | 已验证"不宜久留" |
| 腐化/猩红地下 | 祭坛（26）附近有大量腐化怪；带足药水 | 未验证（没找到） |
