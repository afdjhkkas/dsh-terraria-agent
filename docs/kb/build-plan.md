# 建造方案库（build_plan）

> 只在"要造点什么/改造地形"时加载。所有模板都以**真人物品流**为前提：
> 方块靠 `place` 掏出来放、方块靠 `mine` 挥镐挖、家具靠 `craft` 做 + `place` 放。
> 禁止用 `fill` 以外的一次性脚本凭空生成结构（用户明确要求：不要写一键建造的脚本）。

## 1. 基础建筑标准模板

### 1.1 NPC 房（最小可用，12×8 外框 / 内部 10×5 = 50✗ → 用 14×8）

| 项 | 数值 | 说明 |
|---|---|---|
| 外框 | 14 宽 × 8 高 | 内部 12×5 = **60 格**（正好达下限，建议 12×6=72 更稳） |
| 墙 | 实心方块（木 30 / 石 1 / 土 0 均可） | **不能用平台**（平台不算封闭） |
| 背墙 | 内部每格都要有 wall | `wall` 命令逐格贴，缺一格可能影响判定 |
| 门 | 1 个，`ClosedDoor`（方块 10），锚点=底部格 | 占 3 格高 |
| 家具 | 工作台或桌子 1 + 椅子 1 + 火把/吊灯 1 | 在一条水平地板上 |
| 地板 | 连续实心一整行 | 不能有洞，洞 = 漏 |

**施工顺序（踩过的坑）**
1. 先定外框和地板一行，确认地板行逐格实心。
2. 再砌左右墙、后墙（背墙）。
3. 屋顶最后封 —— 封之前**不要**先放家具，家具会被后来的放置挡住。
4. 封顶时注意：**平台不算封闭**，屋顶必须实心。
5. 门最后装；装门前后的通道要留 3 格高。
6. 判定用 `homeroom`（权威），不要只看 `roomcheck`（当前有 bug）。

### 1.2 竖井（下行通道）

```
每下一格：
  1) 挖两列 floor(cx-0.55) / floor(cx+0.55) 于 py+2
  2) 等 1450~1500ms（挥镐动画 + 服务端同步）
  3) 角色自然下落一格
  4) 每 6~8 格插一根火把（先 `find type:4` 数已有数量）
```
- **禁止**用 `travel down`（会沿斜坡横向漂移，实测 20 格下达 300 格漂移）。
- 水层前先探 `tile.liquid`：≥240 或连续 2 格水 → 停，别挖穿。

### 1.3 横向通道 / 隧道

- 隧道高 **3 格**（身体 3 格），宽按需；只挖 `dy=-2..0`，**不要挖脚下 dy=+1**（会越挖越深）。
- 每 6~8 格插火把；尽头用 `fill` 补回地面防止掉落。

### 1.4 战斗平台（打 Boss 用）

- 多层水平平台，层间 6~8 格，用平台（tile 19）而非实心，方便上下穿。
- 宽度 ≥ 60 格，两端放门/方块挡怪。
- 平台**不能**用来做 NPC 房，但做战斗场地没问题。

## 2. 功能性建筑规范

| 建筑 | 关键要求 | 状态 |
|---|---|---|
| 熔炉/铁砧工位 | 3×2 家具 + 脚下一整行实心 + 上方 2 行空气 | 已验证（熔炉 (2081,303)） |
| 工作台 | 2×1，瞄锚点放 | 已验证 |
| 箱子存放 | 2×2，需实心地板 | 未验证 |
| 刷怪场 | 屏幕外平台 + 火把控制刷怪面 | 未验证 |
| 农场（草药/蘑菇） | 需要对应土壤 + 光源 | 未验证 |
| 水下建筑 | 需排水或水下呼吸；水不能被方块挤出 | 已验证（放不进去） |
| 空岛 | 需铺实体地板防坠落 | 未验证 |

## 3. 方块搭配规范

| 用途 | 推荐 | 原因 |
|---|---|---|
| 承重/地板 | 石 1 / 土 0 | 便宜、`fill` 快 |
| 房屋墙体 | 木 30 | 易得（砍树），视觉正常 |
| 通道照明 | 火把 4，间距 6~8 格 | 实测 43 根/段可把洞穴照亮 |
| 战斗平台 | 平台 19 | 可上下穿 |
| 封水 | 石 1（土会被水冲？未验证） | — |

## 4. 结构布局规范

- 出生点周围 **100 格内不挖**（用户两次从出生点掉进水/坑）。
- 房屋与工位（熔炉/铁砧/工作台）保持 ≤7 格（放置/合成距离限制在 1~7 格）。
- 竖井不要打在房屋正下方（会漏水/漏怪）。
- 横向主通道放在地表下 2~3 格，避免挖穿地表草皮。

## 5. 房屋判定排错流程（当前最重要）

`homeroom` 拒绝时的排查顺序：

1. **先修 `roomcheck`**：`Commands.cs` 里 `RoomCheckCmd/Housing/HomeRoom` 三处都在
   `StartRoomCheck` 之后只调了一次 `WorldGen.CheckRoom(0,1)`。
   正确写法：在房间外扩 70×50 的框里把 `CheckRoom(i,j)` 跑到 `WorldGen.roomCheck == false`，
   再读 `WorldGen.roomCheckFailureReason`（枚举会直接说缺什么）。
2. 面积：内部格数 <60 或 >750。
3. 封闭：逐格扫外壳，任何空气格（含平台、门上方）都是漏。
4. 背墙：内部每格 wall ≠ 0。
5. 家具/光源：工作台/桌 + 椅子 + 火把。
6. 最后用 `homeroom` 复核。

## 6. 安全建造约束

- 改造前先 `scan` 存档现状（出问题能复原）。
- 封顶/补墙时一次只放 1~3 格并回读，避免"以为放上了其实没有"。
- 任何"把角色围起来"的操作（补墙、封顶）之后必须确认角色还能动；
  放完立刻 `state` 看坐标有没有变化。
- 不挖穿水层、不挖穿岩浆层、不在出生点正下方挖。
