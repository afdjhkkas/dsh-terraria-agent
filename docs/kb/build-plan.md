# 建造方案库（build_plan）

> 什么时候加载：要造东西 / 改造地形。
> 前提：一切以**真人物品流**施工 —— 方块靠 `place` 掏、挖靠 `mine`、家具靠 `craft` 做再 `place` 放。
> 用户明确禁止"写个脚本一口气生成整栋房子"；本库只给**判据、尺寸、顺序、坑**。

---

## 1. 基础建筑标准模板

### 1.1 NPC 房（本档唯一通过 `housediag` 的实例）

| 项 | 数值 | 说明 |
|---|---|---|
| 内部净空 | **15 宽 × 5 高 = 74 格**（下限 60，上限 7500） | 外框 17×7 |
| 地板 / 天花板 / 左右墙 | 实心方块（木 30 / 石 1 / 土 0）连续 | **平台 19 不算封闭** |
| 背墙 | 内部**每格** `wall > 0` | 木墙/土墙都行 |
| 门 | 门（tile 10）占 3 格，锚点=底部；**下方实心 + 上方实心** | 缺上方会静默失败 |
| 家具 | 平坦面 ×1（桌 14 / 工作台 18）+ 舒适物 ×1（椅 15） | 铺在同一条地板上 |
| 光源 | 火把 4 ×1~2 | 别挡门口 |
| 验收 | `housediag` → `valid:true, missing:[]` | 本档实测 `tiles:74, walled:74/74, light:2, comfort:2, flat:2` |

**施工顺序（错序会返工）**

1. `scan` 存现状（出问题能复原）。
2. 先定**地板行**，逐格 `tile` 确认实心（别信"应该放上了"）。
3. 砌左右墙 → 贴背墙（`wall`）→ 封天花板。
4. 封顶**之前**别放家具（后放的方块会挡住先放的家具）。
5. 门最后装：门位挖成 3 格高、下方与上方都要实心。
6. `housediag` 复核；`valid:true` 才算完成。

### 1.2 竖井（下行，本档唯一稳定下行方式）

```
每下一格：
  1) mine 两列：colL=floor(cx-0.55)、colR=floor(cx+0.55)，y = py+2，ms=1500
  2) 等 ~1.5s（挥镐 + 服务端同步），角色自然下落
  3) 每 6~8 格插一根火把（先 find type:4 数已有）
  4) 落水检查：脚下两列 3 行，liquid ≥240 或连续 2 格水 → 停
```
- **禁止** `travel down`：实测下 20 格横漂 300 格。
- 井底留 ≥3 格横移空间，否则到底被卡死。
- 想再上来：只在铺了绳子（213）的井里 `climb up`；否则 `mirror`。
- 竖井起点离出生点 **≥100 格**（两次把出生点挖穿进水里）。

### 1.3 横向通道 / 隧道

- 高 **3 格**（角色 3 格高），只挖 `dy=-2..0`。
- **不要挖 `dy=+1`**：实测会越走越深（一次下沉 80+ 格）。
- 每 6~8 格火把；尽头用 `fill` 补回地板防掉落。
- 挖出来的东西**不会自动入包**：每挖 4~6 格 `grab` 一次。

### 1.4 楼梯 / 台阶（三次失败换来的规则）

- 台阶必须砌在**地板行**上；砌在身体高度只会变成一堵墙。
- 一格晋升可以靠游戏自动迈步；两格必须跳。
- 空腔里搭台会"跳上去又落回"，因为放置无支撑 → 先在脚下垫一格再搭。

### 1.5 战斗平台（打 Boss）

- 多层平台（tile 19 可上下穿），层间 **6~8 格**，宽 ≥60 格。
- 两端用方块封住挡怪；平台下留 3 格通道便于跑位。
- 平台**不能**当 NPC 房顶/墙。

## 4. 结构布局规范

- **出生点周围 100 格内不向下挖**（用户明确要求；两次挖穿进水）。
- 工位与常用站位 ≤7 格（放置/合成距离），合成最好 ~1 格。
- 竖井不要打在房屋正下方（漏水/漏怪/塌方）。
- 横向主通道放地表下 2~3 格，避免挖穿草皮。
- 两间房之间留 **3 格走道**，门开在走道侧（背靠背会把两间并成一间，白丢一个房位）。
- 建造前**清场**：树是实心的，会挡走位、占内部格 → 先砍树再盖。
- 基地边缘要有护栏，不然自己挖的坑口就是死亡陷阱（实测 y 303→466）。

## 5. 安全建造约束

```text
改造前：scan 一份现状
每一步：只放 1~3 格 → tile 回读 → 再放
每阶段末：state 确认 (tile, life, wet, dead)
```

- 任何"把角色围起来"的操作（补墙/封顶/贴背墙）之后**立刻确认还能动**。
- 不挖穿满格水腔/岩浆；不往水里放方块（挤不出去，9 次全失败）。
- 背包满时别大规模施工（挖出来的捡不到 = 白干）。
- 补地板要**自下而上**：`fill` 从最低一行往上铺，否则整行空气的第一格就失败。
- 填完若把自己埋住，立刻挖开自身碰盒（`x: px..px+1, y: py-1..py+1`）。

## 6. 特殊环境建造

| 环境 | 要求 | 状态 |
|---|---|---|
| 水下 | 要么排水（**做不到**，水不能被方块挤出），要么水下呼吸（鱼鳃/海神贝壳） | 已验证"排水不可行"；水下呼吸药**无配方**（缺水叶/珊瑚） |
| 深部水层（y≥380） | 无呼吸道具就别去；矿再多也不划算 | 已验证（`travel down` 到 381 即停） |
| 岩浆（y≈466 见过） | 抗火/黑曜石皮肤，落点必须垫实心 | 未验证 |
| 空岛 | 铺实体地板防坠 + 长距离可达（翅膀/抓钩） | 未验证（没找到空岛） |
| 雪原 | 无冻伤机制，但怪强、地形陡；本档 5 次尝试全死 | 已验证"不宜久留" |
| 沙漠 | 层状砂岩常从**上方**挡路；蚁狮会追 | 已验证（东行 500+ 格） |
| 丛林 | 挖掘 1.3 秒/格、水囊多、怪多 | 已验证（x≈2800 起） |
| 腐化/猩红地下 | 祭坛附近怪多，带足药水 | 未验证（没找到） |
