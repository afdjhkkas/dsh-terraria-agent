# 建造标准知识库（build_standard）

> **只写与地图无关的建造规范**：结构怎么算合理、房子怎么才算合格、平台怎么搭才不出事。
> 尺寸给的是**相对约束**（"至少能站人""必须留出口"），不是某一次建造的固定长宽。

---

## 1. 通用建造规范

- **结构稳固**：不要留下悬空无支撑的大块结构；方块塌落会连带破坏上方建筑。
- **通路通畅**：完工后自己能从头走到尾；门口、楼梯口、拐角处至少留 3 格净高。
- **分层施工**：先地基/地板 → 再侧墙 → 再背景墙 → 再屋顶 → 最后家具光源与门。
  先铺天花板会让后续补墙变得极难。
- **区分四类组件**：实心方块（承重/围合）、背景墙（封闭/防刷怪）、光源、家具与入口。
  混用会导致"看着像个屋子，判定不通过"。
- **拆之前先想清楚承重**：拆墙根会让上面塌；拆屋顶会灌水、灌怪。
- **留检修口**：给竖井/地下工程留一段可爬出通道，避免把自己封在下面。
- **不要在水下施工**：先把水隔开或排水，否则放置会被水流冲掉。

## 2. NPC 房屋通用建造规范

一间合格房 = **封闭 + 满墙 + 光源 + 平面物 + 坐具 + 门 + 无污染 + 面积达标**。

- **四周墙体封闭**：实心方块围一圈，不留缺口；角上尤其容易漏一格。
- **内部铺满背景墙**：每一格都要有墙，包括门后和家具背后；漏一格就可能判失败。
- **至少一处有效光源**：火把即可；光要落在房间内部，不是墙外。
- **桌椅齐全**：一件平面放置物（桌/工作台）+ 一件坐具（椅）。
- **必须有门**：门要装在墙上、能开合，门外要有落脚点。
- **门的过梁**：门占 1 宽 × 3 高，这三格必须全空，**上方紧贴的一格必须是实心方块**，下方必须是实心地面。
  只满足「3 格空 + 有地板」游戏会直接拒绝放置，而且不会有任何提示。
- **家具要落在实心方块上**：家具的支撑面必须是普通物块；墓碑、工作台、平台这类"框架物块"不能当地基，
  放上去会静默失败。找不到平地时先补一块普通方块，再把家具放上去。
- **净高与净宽**：内部至少 4 格净高（能站人 + 头顶留空），宽度要放得下门、桌椅且人能走动。
- **屋内不要留污染方块**：腐化/猩红方块一格都不能有；建议外墙就用不可侵蚀材料。
- **不要用平台当墙体**：平台的侧向不算封闭，拿它当左右墙必然判失败。
- **平台可以当屋顶，但会少几格空气**：游戏对天花板的判定认「能站人的面」，平台算。
  代价是平台那几格不计入房间内部空气，本来刚好达标的房可能因此掉到线下；先把面积留足再换。
- **屋外留出进出门的空地**：NPC 会出门走动，门口被堵会把 NPC 卡在屋里。
- **多间房必须物理隔断**：共用一面墙可以，但中间要完全封死，不能有大开口互通。

### 自建房的出口设计（自己进出不许拆墙）

玩家自己盖的房子是**建筑**，不是地形。走到墙前不能按"挡路就挖"处理，那会把刚盖好的房拆掉
（房间立刻从封闭变成漏水，NPC 入住判定作废）。

出口按优先级选：

| 顺序 | 做法 | 说明 |
|---|---|---|
| 1 | **走门** | 门的格子对通行判定是"可穿过"，走过去会自己推开；关着时开门即可，不需要挖 |
| 2 | **屋顶留平台口** | 盖房时在屋顶连续放 **1~2 格平台**代替实心块。平台可从下方跳穿、也可在平台上按"下"落穿，人和 NPC 都能过，且仍算天花板 |
| 3 | **窗外跳出去** | 若屋顶没留口，找房子外侧的落脚点（平台/台阶）从上沿翻出去 |
| 4 | 最后才考虑改动 | 必须改也得先确认这一格不是房间边界（边界在 box 之外一圈），改完立刻回读房间是否仍合格 |

**判定"这堵墙是不是我造的"不能只看方块类型**——自建房的墙和地板用的就是普通土石/木材，
和天然地形一模一样。区别只能来自**建造方自己登记的"已建结构"清单**：进出这类结构时
一律走门/平台口，禁止挖。

## 3. 各类平台建造规范

| 类型 | 要求 |
|---|---|
| **战斗平台** | 表面完整平整、无凸起与缺口；层与层之间高度要能靠跳跃或钩爪够到；每层留出跑动空间，不要贴天花板 |
| **刷怪平台** | 离地面足够高、**不放光源**、表面平整；四周做挡墙防止玩家被推下去；配合水蜡烛/战斗药水提高效率 |
| **交通平台** | 连续平顺、高度对齐、无断层；拐弯处做成斜坡或台阶；长距离每隔一段留一个落脚平台 |
| **农场平台** | 分区隔离（不同作物/不同怪各一层）；用实体方块与背景墙阻断污染与刷怪；留出收割通道 |
| **空岛/高空建筑** | 必须先做承重柱或悬挂结构；地基至少两层，防止失足坠落 |

## 4. 方块搭配通用规范

- **外墙用稳定、不可侵蚀的材料**（木材、砖、石都可以）；腐化区尤其不要用可侵蚀方块做外皮。
- **内墙尽量统一**，减少零散替换；不同材质混搭只影响观感，不影响判定。
- **背景墙尽量连续**：零散空洞既影响判定，也会变成刷怪点。
- **光源均匀分布**：一处强光盖不住整间大屋，按房间分段布置。
- **居住建筑禁用**：岩浆、腐化/猩红/神圣污染方块、爆炸物。
- **地板优先实心方块**：平台做地板会让 NPC 掉下去、也会让家具放不稳。
- **颜色/材质可以自由搭配**：不影响功能，只影响观感与抗侵蚀能力。

## 5. 地形改造规范

- **平整地形统一高度**：改完要能一眼看出走线，避免高低不平导致卡脚。
- **坑洞回填要逐层**：从下往上填，一次填一整排会因为没有支撑而失败。
- **斜坡要平缓**：用半砖/斜面过渡，不要留 1 格高的断崖（角色会被卡住）。
- **隧道只挖上半身**：水平隧道保持 3 格净高，**不要挖脚下那一格**，否则整条道会一路下沉。
- **竖井要两列**：角色碰撞盒比一格宽，只挖一列会卡住；挖两列并用绳子/阶梯上下。
- **改完立刻自检**：能走通吗？会不会掉下去？水/岩浆会不会灌进来？
## 建造顺序：先背墙，再家具，最后封口

这一条是**顺序性规则**，顺序错了就会卡死（不是判定失败，是"够不到"）：

1. **先铺背景墙**（人还站在空地上）：墙只能放在**没有方块的格子**上，
   有方块挡着会报「这一格有方块挡着，先 mine 掉再放墙」。
2. **再放家具**（工作台 / 桌子 / 椅子 / 火把）：家具需要"下方有支撑"，
   所以地面那一行必须先存在。
3. **最后砌侧墙和天花板、装门**。一旦四面封闭，人就在外面，
   内部格子超过手臂长度（约 7 格）→ 所有室内操作都报「够不到」，
   只能拆墙重开。

**推论**：房间不是"从外往里装"的，是"人在里面装完了再封口"。
先封口的房间，室内背墙和家具会永远缺着，永远判定不合法。

**墙面判定用的字段**：`tile` 返回的 `solid`（能否当支撑/落脚）和 `wall`（背景墙 id）；
`type > 0` 不代表能站——树干是 `hasTile:true` 但 `solid:false`。

## NPC 住房：建造子任务逻辑（七步，顺序不许换）

主目标是**"一间游戏认可的可入住房屋"**，不是"用现成地形凑一间"。四条禁令先摆明：

- **禁止拿地图原生地形凑房子**：山洞、地洞、沙漠小屋都不算自建房屋；墙不够、空间不对都要自己补。
- **禁止用自然背景墙**：泥土墙、岩石原生墙等 `wallHouse=false`，铺满也一堵都不算。
- **禁止跳过自检就宣布完成**：`place`/`wall` 返回 ok 只说明"挥了"，不说明"能住人"。
- **禁止先封口**：人必须能在屋里活动，封口之后室内格子超过手臂长度就永久"够不到"。

### 七步

| 步 | 动作 | 判定/证据 |
|---|---|---|
| 1 选址 | 选一段**平坦**地面（连续若干列地面行一致），不选斜坡、树根、水边 | 逐列读 `tile.solid`，地面行差 ≤0 |
| 2 清理 | 把内部**杂草、悬空植物、多余方块、多余墙**全部清掉，做成干净空腔 | 内部每格回读 `type === -1` |
| 3 进门 | 角色先站到房间内部（这一步不能省） | `state.player.tile` 在内部范围内 |
| 4 铺墙 | 用**人工墙**（`wallHouse=true`，例如木墙）逐格铺满内部四面 | 每格回读 `wallHouse === true` |
| 5 家具 | 先放桌椅（舒适度）、再放火把（光源）：都要"下方有支撑" | `comfort ≥ 1`、`light ≥ 1` |
| 6 封口 | 砌侧墙 → 砌天花板 → 侧墙底部拆三格装门 | `enclosed === true`、`doors ≥ 1` |
| 7 自检 | 跑房屋判定清单，六条全过才算完成 | 见下节；任一条不过 → 按 fix 修，不许收工 |

### 自检判定条目（六条，机器可判）

| # | 条目 | 通过条件 | 不通过时自动修正 |
|---|---|---|---|
| 1 | 封闭实体边框 | `enclosed === true` | 定位缺口格，补实心方块 |
| 2 | 人工背墙铺满 | 内部每格 `wallHouse === true` | 换人工墙重铺；自然墙先锤掉 |
| 3 | 有门 | `doors ≥ 1` | 侧墙底部拆三格装门 |
| 4 | 有光源 | `light ≥ 1` | 屋内靠墙/地面放火把 |
| 5 | 桌椅等舒适物 | `comfort ≥ 1` | 放桌子/工作台 + 椅子 |
| 6 | 空间合适 | 封闭区域 30~7500 格 | 太大就加内部隔墙，太小就扩 |

**权威判据**：有没有"住房墙"只看 `tile.wallHouse`（原版 `Main.wallHouse[wallType]`），
不是 `wall != 0`。代码实现与单测：`src/house-audit.js`、`test/house-audit.test.js`。

**输出约定**：自检不通过时，输出"缺陷清单 + 每条对应的修正动作"，
而不是"房屋已完成"；修完必须重新自检，直到六条全过。

## 选址判据：先问"里面是空的吗"

建房失败的绝大多数不是放置技巧，是**选错了地方**：

- 必须同时满足两条：**① 8 列地板行同高；② 内部 4 行全空**（每格 `type === -1`）。
- 只要内部有实心方块，角色就进不去 → 后面所有 `mine` / `wall` / `place` 都因为靠近不了而失败，
  报错看起来像"工具坏了"（「有方块挡着」「够不到」），其实是选址问题。
- 斜坡山体、树根正下方、洞穴顶都不是好地方；地表面本身起伏时先整平（填方 → 再摆）。

**清理一步的验收标准是 `type === -1`，不是"我 mine 过了"**：一次挥镐不一定挖掉，
必须回读确认；没掉就再挖，挖不动就换址。

**失败归类顺序**（按这个顺序排查，不要先怀疑工具）：
1. 进不去（内部不是空腔）→ 换址或先开路
2. 够不到（> 7 格）→ 走过去（走路要带跳跃）
3. 墙不是人工墙（`wallHouse=false`）→ 换人工墙
4. 才有可能是放置时序问题（时长/重试）

## 建房流程（六步，清场是第一步，不许跳）

| 步 | 动作 | 验收 |
|---|---|---|
| 1 划范围 | 定出房屋外框，**再向外扩 1 格作缓冲区** | 范围确定，缓冲区一起算进去 |
| 2 清场 | 清掉范围内**所有实体障碍**：树干/树冠、杂草植被、多余石块 | 每格回读 `type === -1` |
| 3 搭框架 | 砌地面/侧墙/天花板（人先进内部） | `enclosed === true` |
| 4 铺墙 | 铺**人工背景墙**（`wallHouse === true`） | 内部每格 `wallHouse` 为真 |
| 5 家具 | 桌椅 + 光源 + 门 | `comfort ≥ 1`、`light ≥ 1`、`doors ≥ 1` |
| 6 校验 | 跑 NPC 入住六条 | 六条全过才算完成 |

### 树木属于必须清理的障碍（不能保留、不能贴着墙）

- 树干、树冠都占格，**即使 `solid=false` 也算房屋阻挡物**，规划范围内一律砍掉。
- 缓冲区（外扩 1 格）里的树也要清：树干贴着墙、穿插进墙体都算不合格。
- 判断顺序：先分辨"这格是树/植被还是地形"，再决定"砍还是挖"——砍树用斧、挖地形用镐。

### 顺序的意义

清场没做完就搭框架，会出现"人进不去 / 被树干穿墙 / 墙铺不上"这一整串连带失败；
它们看起来像工具坏了（「有方块挡着」「够不到」），根因都是**没清场**。

## 施工物理约束（放/挖的真实限制）

这一节全是**与世界种子无关**的引擎约束，任何世界都一样；违反它们时表现都像“工具坏了”。

| 约束 | 表现 | 做法 |
|---|---|---|
| **接邻支撑**：方块必须与已有实心格共边才能放 | 空中凭空放一律被拒，命令回 `armed: true` 但世界没变 | 贴已有墙体逐格延伸；砌墙自下而上、铺顶自左而右（每格靠前一格支撑） |
| **作用距离上限**：放/挖/交互约 7 格（水平、垂直各自计） | 报“够不到” | 先走到或跳到目标旁；够不到就搭一格台阶站上去 |
| **先封顶，再往下挖**：脚下永远够得着，头顶很快够不着 | 想加高房间时天花板越放越放不到 | 扩容积优先**向下挖深**，不要向上加高；已拆顶就按原高度重新封顶 |
| **家具需要支撑**：椅/桌/工作台/火把要落在地板或墙上 | 挖掉家具脚下那格，家具掉成掉落物，舒适度随之失效 | 家具最后放；放前确认脚下 `solid` 为真 |
| **背景墙必须是人工墙** | 自然墙铺满也不算（`wallHouse` 为假） | 只铺 `wallHouse` 为真的墙；自造木墙 1 木材出 4 面 |
| **合成要看合成站距离** | 野外合成报“附近没有这个配方需要的工作站” | 工作台/熔炉放在身边（同一间房里）才合成 |
| **成功以世界状态为准** | 命令回 `armed: true` 只代表“挥动了” | 每次放/挖都用 `tile` 回读确认 |

> 落地验证：按这七条把一间 8x8x8（64 格）房间从“放不下/够不到/背墙不全”修到 `housediag` 六条全过（`valid` 为真），再用 `homeroom` 成功给向导指派新家。
- **平台（tile 19）能从下方跳穿**：真人按住空格从地面一帧升 1.2 格、穿过多层平台后落在上一层；
  桥实测从地面满跳直接站上 4 格高的平台（232.7 → 227.7），再跳 5 格站上第二层（227.7 → 222.7）。
  所以“层高多少合适”没有硬指标——**只要满跳（6.1 格）够得着就行**，留一格余量即可。
- 搭多层时先用平台铺一整条横线，人站在下面往上跳就能站上去；要落到下一层则按“下”键（按住才穿）。
