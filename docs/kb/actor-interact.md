# 交互行为库（actor_interact）

> 什么时候加载：怎么动 / 怎么打 / 怎么捡 / 怎么跟 NPC 打交道 / 怎么用药。
> 总原则：**控制角色，不改变世界** —— 每个动作都必须是玩家按键也能做出来的。

---

## 1. 角色移动逻辑

### 1.1 已量到的物理量（本档实测）

| 量 | 数值 | 来源 |
|---|---|---|
| 玩家碰撞盒 | 20×42 px ≈ **1.25 宽 × 2.6 高**，占 3~4 格行 | 实测卡墙位置反推 |
| 中心点约定 | `state.player.tile` 是**中心点**；脚在地板 y=F 时中心 ≈ F-1.3 | 实测 |
| 行走速度 | 强制 `velocity.X=±2.8` px/tick ≈ **11 格/秒**；800ms 走 ≈8.8 格 | 实测 |
| 摩擦停止 | 松手后 ~100ms 内停下 | 实测 |
| 跳跃高度 | 一次 `velocity.Y=-5.6` ≈ **2.3 格**，滞空 ≈350ms | 实测 |
| 自动迈步 | 1 格高差自动上；2 格必须跳 | 实测 |
| 游戏物理仍生效 | 重力/摩擦/碰撞在强制速度之上照常 | 实测 |

### 1.2 各种地形的走法

| 场景 | 做法 | 已踩过的坑 |
|---|---|---|
| 平地 | `move {dir,ms}`，单步 ≤1500ms，走完读 `state` | 一次走太久撞墙/掉坑还不知道 |
| 下竖井 | 逐格 `mine` 两列（`floor(cx±0.55)`, `y=py+2`, `ms=1500`）→ 等 1.5s 自然下落 | 别用 `travel down`（横漂 300 格） |
| 上竖井 | 只能靠绳子 `climb up`，起步 x 对齐 `col+0.5` | 没绳爬不上；空腔里挂不了绳 |
| 过薄水层 | `liquid<240` 直接走 | 满格水会溺水（约 10 秒开始掉血） |
| 跨沟 | `jump` + 前进，一次 1~2 格 | 宽沟先垫方块 |
| 沙地 | 正常走，注意上方层状砂岩 | 挡路的常常是**头顶那几格** |
| 自动寻路 | `path {x,y}` 只用于开阔地 | **空腔竖井死锁**（原地弹 60 秒） |
| 跟玩家 | `follow {player,range}`；`idle` 取消 | 多人时用 |

**每次移动后的固定检查**：`state.player.tile / life / wet / dead`。
位置 10 秒不变 = 卡住 → 立刻换策略（挖 / 跳 / 垫 / 钩 / `mirror`），不要原地重试。

### 1.3 卡住时的五种脱困（按代价排序）

1. `jump` + `move` 斜蹭（1 格台阶 / 浅坑）。
2. `hook` 抓上方或侧壁（有钩时最省事）。
3. 逐格 `mine` 挖出 3 格高通道 + `place` 垫脚。
4. 用绳子（自己铺 213）`climb`。
5. `mirror` 回出生点（**从深坑回地表最可靠**，代价是丢位置）。

## 2. 战斗行为规范

- 只主动打 **8 格内**；"16 格内见谁打谁"会让赶路推进变成 0。
- `attack {who?,x?,y?,r:12~22,ms:150~400}`；`r` 是硬半径，`r=8` 打 8.4 格会拒。
- 开打前 `select` 到武器槽；弓/枪要 `shoot` + 确认弹药（`inventory` 看箭）。
- 走真实伤害管线：`GetTotalDamage().ApplyTo(item.damage)`；命中受全局无敌帧约束（10 tick ≈167ms），所以**用 `npc.life` 差值判命中**，不要数挥击次数。
- `guard` **默认开**：只打视线内目标（隔墙打不到只会挨打）。用户明确要求"不要站着挨打"。
- hp **50~55% 停手**，<35% 撤退（上跑 / `mirror`）。
- 夜间 + 下雨别在野外静止（实测站 24 秒被打死）。
- 打完 `npc {r}` 确认没漏、`items` 看掉落、`grab` 收。

## 3. 物品拾取 / 使用逻辑

| 动作 | 命令 | 规则 |
|---|---|---|
| 看掉落 | `items {r}` | `Main.item[]`；远处能看到但捡不到 |
| 拾取 | `grab {r}` | 只吸脚边 **≤4 格**；**背包满静默失败**（`picked:0`） |
| 挖矿掉落 | 自动掉落 | 掉在被挖的格子上，走开就丢 |
| 换手持 | `select {slot|item}` | 回读 `held` 确认 |
| 用物品 | `use {slot,right,ms,x,y}` | 药水/食物/右键交互 |
| 喝药 | `heal` | 有冷却（具体秒数未测） |
| 放方块 | `place {x,y,type}` | 必须回读 `type` 真变了；`armed:true` 不算 |
| 清背包 | `drop {slot,count}` | 先丢垃圾（多余工具/脚镣/旗帜）再挖 |

**背包管理**：主背包 50 格。挖矿前 `inventory` 看 `main_slots_used`，≥45 先清；满了不仅捡不到，还会**误以为"拾取坏了"**（真踩过）。

**研究/复制（Journey）**：`research {slot}` 到 100/100 后 `duplicate {item,count}` 无限取；只对已研究过的物品有效。

## 4. NPC 交互逻辑

| 动作 | 距离 | 命令 | 备注 |
|---|---|---|---|
| 对话 | <11 格 | `talk {npc}` | 打开对话（必须真走近） |
| 看商店 | <12 格 | `shop {npc}` → `shops` | `shopId=1` 是商人（14 件货） |
| 购买 | <12 格 | `buy {shopId,slot}` | 走 `Player.BuyItem` 真扣钱（实测火把 1138→1088 铜） |
| 出售 | <12 格 | `sell {slot}` | 换钱 |
| 让 NPC 回家 | — | `homeroom {x,y,who}` | 原版 `moveRoom`；**本档判定坏，搬不动**（game-rule §3.2） |

- 必须**真的走过去**再交互（用户明确要求：不要凭空开商店买东西）。
- 无家 NPC 也能交易，只是乱走、容易掉坑；能救就救（合法房 + 等游戏分配，或让用户手动点一次）。
- NPC 会挡门/挡路：站开一点再操作。
- 商人已知货价：铁砧 50 银、挖矿头盔 400 银、存钱罐 100 银、虫网 25 银、铜镐 5 银、铜斧 4 银、火把 50 铜、弱效治疗药水 300 铜、绳 10 铜。

## 5. 召唤物操作逻辑

- `minion {slot}` 召唤/收回；召唤物自己打怪，不需要瞄准。
- 召唤栏有限（默认 1），换召唤物会顶掉旧的。
- `state` 里看 `minions` 数量；召唤物死亡要重新召。
- 召唤物不挡自己挥击，但会抢掉落位置（不影响拾取）。
- 本档有雀杖（物品），召唤效果**未实测**。

## 6. 药水 / 增益使用策略

| 场合 | 用什么 | 时机 |
|---|---|---|
| 洞穴探索 | 治疗药水 | hp <60% |
| 打 Boss | 铁皮 + 再生 + 敏捷 + 治疗 | 开战前全喝，治疗留到 50% |
| 长途赶路 | 敏捷/迅捷 | 出发前 |
| 溺水风险 | 鱼鳃/水下呼吸 | 入水前（本档做不出来） |
| 夜间野外 | 火把 + 治疗 | 常备 |

- 药水有冷却，别连喝；`state.player.buffs` 查当前增益。
- 死亡后增益消失（未验证），复活后要重喝。
- 稀有药水（虫洞/回城）留给"卡住/必死"的场合。

## 7. 一次动作的标准循环（所有行为的公共骨架）

```
1. 看：state / tile / scan / inventory（拿当前真值，不靠记忆）
2. 做一个小动作：≤1.5 秒的量，一次只改一件事
3. 立刻回读：tile.type / inventory 差值 / state.player.tile
4. 不符预期 → 换策略（同一个失败动作最多重试 2 次）
5. 每 3~6 步插一次安全检查：hp、坐标没退、没落水
```

### 7.1 三个"看起来在干活、实际没干"的陷阱

| 现象 | 真因 | 判据 |
|---|---|---|
| 挥镐动画不播、格子不动 | 自己每帧塞 `mouseLeftRelease=true` 把挥动重置了 | `state.player.itemAnimation` 恒 0 |
| 放置"成功"但没放下 | 只挥了一下（`armed:true`）或与自身碰撞盒重叠 | 回读 `tile.type` 没变 |
| 拾取"坏了" | 背包满 / 距离 >4 格 / 掉落物掉在别格 | `inventory.main_slots_used`、`items` 坐标 |
