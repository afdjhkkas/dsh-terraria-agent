# 交互行为库（actor_interact）

> 什么时候加载：怎么动 / 怎么打 / 怎么捡 / 怎么跟 NPC 打交道 / 怎么用药。
> 总原则：**控制角色，不改变世界** —— 每个动作都必须是玩家按键也能做出来的。

---

## 1. 角色移动逻辑

| 场景 | 做法 | 坑（实测） |
|---|---|---|
| 平地行走 | `move {dir,ms}`，单步 ≤1500ms，走完读 `state` | 一次走太久会撞墙/掉坑，且不知道路上发生了什么 |
| 下竖井 | 逐格 `mine` 两列（`floor(px±0.55)`，y=py+2，ms=1500）→ 等 1.5s 自然下落 | 别用 `travel down`（横向漂移） |
| 上竖井 | 只能靠绳子：`climb up`，起步前 x 对齐 `col+0.5` | 没绳子爬不上去（原版设计）；坑里挂不了绳（无支撑） |
| 过水 | 薄水层（liquid<240）直接走；满格水禁止进入 | 无水下呼吸会溺死；水不能被方块挤出 |
| 跨沟 | `jump` + 前进；宽 >3 格先垫方块 | 一次只跳 1~2 格 |
| 自动寻路 | `path {x,y}` 只用于开阔地 | **空腔竖井死锁**：原地弹 60 秒 y 只回到 421 |
| 跟随玩家 | `follow {player,range}`；`idle` 取消 | 多人同玩时用 |

**每次移动后的固定检查**：`state.player.tile / life / wet / dead`。
位置 10 秒不变 = 卡住 → 立刻换策略（挖 / 跳 / 垫 / `mirror`），不要原地重试。

### 卡住时的四种脱困（按代价排序）

1. `jump` + `move` 斜向蹭（浅坑、1 格台阶）。
2. `hook` 抓上方/侧壁（有抓钩时最省事）。
3. 逐格 `mine` 挖出 3 格高通道 + 用 `place` 垫脚下。
4. `mirror` 回出生点（**从深坑回地表最可靠**，代价是丢位置）。

## 2. 战斗行为规范

- 只主动打 **8 格内**的敌人；16 格内"见谁打谁"会让赶路变成 0 格推进。
- `attack {who?, x?, y?, r:12~22, ms:150~400}`；`r` 是**硬半径**，`r=8` 打 8.4 格外的目标会被拒。
- 开打前 `select` 到武器槽（别空手挥）；弓/枪要 `shoot` + 确认有弹药。
- `guard` **默认开**：只打视线内的敌人（隔墙打不到只会挨打）。用户明确要求"不要站着挨打"。
- hp 掉到 **50~55% 停手**，<35% 撤退（往上跑 / `mirror`）。
- 夜晚别在 NPC 聚集地外单独硬刚（僵尸成群）；墓地/腐化夜怪更强。
- 打完检查：`npc {r}` 确认没漏，`items` 收掉落。

## 3. 物品拾取 / 使用逻辑

| 动作 | 命令 | 规则 |
|---|---|---|
| 拾取 | `grab {r}` | 只吸脚边 ~4 格；**背包满会静默失败**（`picked:0`） |
| 看掉落 | `items {r}` | 掉落物在 `Main.item[]` 里；远处也能读到但捡不到 |
| 挖矿掉落 | 自动 | 掉在挖出的格子上，走开就捡不到 |
| 换手持 | `select {slot|item}` | 回读 `held` 确认 |
| 用物品 | `use {slot,right,ms,x,y}` | 药水/食物/放置类 |
| 喝药 | `heal` 或 `use` 药水槽 | 药水有冷却（未验证具体秒数） |
| 放方块 | `place {x,y,type}` | 必须回读 `type` 变了才算放下；`armed:true` 不算 |
| 清背包 | `drop {slot,count}` | 先丢垃圾（多余工具/脚镣/旗帜）再挖 |

**背包管理**：主背包 50 格；满了以后 `mine` 能挖但**捡不到**，掉落物会消失。
规则：挖矿前 `inventory` 看 `main_slots_used`，≥45 先丢/存。

## 4. NPC 交互逻辑

| 动作 | 距离 | 命令 | 备注 |
|---|---|---|---|
| 对话 | <11 格 | `talk {npc}` | 打开对话 UI（客户端本地） |
| 看商店 | <12 格 | `shop {npc}` → `shops` | 返回 `shopId` 与货架 |
| 购买 | <12 格 | `buy {shopId,slot}` | 要钱（铜币） |
| 出售 | <12 格 | `sell {slot}` | — |
| 让 NPC 回家 | — | `homeroom {x,y,who}` | 原版 `moveRoom`；**引擎判定坏，目前搬不动**（game-rule §3.2） |

- 必须**真的走过去**再交互（用户明确要求：不要凭空打开商店 UI 买东西）。
- 无家 NPC 也能买卖，只是会乱走/掉坑；能救就救（建合法房 + 等游戏自己分配，或让用户点一次）。
- NPC 会挡门/挡路：站开一点再操作。

---

## 5. 召唤物操作逻辑

- `minion {slot}` 召唤/收回；召唤物自己打怪，不需要瞄准。
- 召唤栏有限（默认 1），换召唤物会顶掉旧的。
- 召唤物死亡/离开要重新召（`state` 里 `minions` 数量可查）。
- 召唤物不挡自己挥击，但会抢掉落位置（不影响拾取）。

## 6. 药水 / 增益使用策略

| 场合 | 用 | 时机 |
|---|---|---|
| 探索洞穴 | 治疗药水 | hp <60% |
| 打 Boss | 铁皮 + 再生 + 敏捷 + 治疗 | 开战前全喝，治疗留到 50% |
| 长途赶路 | 敏捷/迅捷 | 出发前 |
| 溺水风险 | 鱼鳃/水下呼吸 | 入水前 |
| 夜间野外 | 火把 + 治疗 | 常备 |

- 药水有冷却，别连喝；`state.player.buffs` 查当前增益。
- 增益死亡后消失（未验证），死后重新喝。
- 稀有药水（虫洞/回城）优先留给"卡住/必死"的场合。

## 7. 一次动作的标准循环（所有行为的公共骨架）

```
1. 看：state / tile / scan / inventory（拿到当前真值）
2. 做一个小动作：≤1.5 秒的量，一次只改一件事
3. 立刻回读验证：tile.type / inventory 差值 / state.player.tile
4. 不符预期 → 换策略（不重复同一个失败动作，最多重试 2 次）
5. 每 3~6 步插一次安全检查：hp、坐标没退、没落水
```
