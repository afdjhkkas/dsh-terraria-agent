# 交互行为库（actor_interact）

> 只在"怎么动 / 怎么打 / 怎么捡 / 怎么跟 NPC 打交道"时加载。
> 原则：**控制角色，不改变世界** —— 每个动作都必须是玩家按键也能做出来的。

## 1. 角色移动逻辑

| 场景 | 做法 | 坑 |
|---|---|---|
| 平地行走 | `move {dir,ms}`，单步 ≤1500ms，走完读 `state` 确认位移 | 一次走太久会撞墙/掉坑，且不知道路上发生了什么 |
| 下竖井 | 逐格 `mine` 两列 + 等 1450ms，角色自然下落 | 不要 `travel down`（会横向漂移） |
| 上竖井 | 必须靠绳子：`climb up`，起步前 x 对齐到绳列 +0.5 | 没绳子爬不上去（原版就这么设计的） |
| 攀绳下行 | `climb down`；绳子要先把背包里的绳铺进竖井 | 坑里挂不了绳（无支撑） |
| 过水 | 薄水层直接走（liquid<240）；满格水禁止进入 | 水下无呼吸会溺死 |
| 跨沟 | `jump` + 前进；宽 >3 格先垫方块 | — |
| 自动寻路 | `path {x,y}` 仅用于开阔地；空腔竖井会死锁 | 见 game-rule §7 |

**每次移动后的固定检查**：`state.player.tile`、`life`、`wet`、`dead`。
位置 10 秒没变 = 卡住，立刻换策略（挖/跳/垫），不要原地重试。

## 2. 战斗行为规范

- 只打 **8 格内**的敌人（16 格内全打会让赶路变成 0 格推进）。
- `attack {x,y,r:12,ms:150~400}`；`r` 用 12~22，`r=8` 打 8.4 格外的怪会被拒。
- 开打前**掏出武器**（`select` 到武器槽），不要空手挥。
- hp <50~55% 停手回血；<35% 撤退（往上跑/回城）。
- `guard` 默认开：只打视线内的敌人，避免隔着墙打不到还挨打。
- 弓/枪类要 `shoot`，弹药槽要确认有箭；近战用 `attack`。

## 3. 物品拾取 / 使用逻辑

| 动作 | 命令 | 规则 |
|---|---|---|
| 拾取 | `grab` | 只吸脚边 ~4 格；**背包满会静默失败**（先丢垃圾/做箱子） |
| 挖矿掉落 | 自动 | 掉在挖出的格子上；走开 4 格就捡不到 |
| 换手持 | `select {slot|item}` | 回读 `held` 确认 |
| 用物品 | `use {slot,ms,right}` | 药水/食物类；`right:true` 是右键交互 |
| 喝药 | `heal` 或 `use` 药水槽 | 药水有 60s 冷却（未验证具体值） |
| 放方块 | `place {x,y,type}` | 必须真的消耗背包方块；回读 `type` 才算成功 |

**背包管理**：主背包 50 格；满了之后 `mine` 能挖但捡不到。定期丢垃圾或做箱子存。

## 4. NPC 交互逻辑

| 动作 | 距离 | 命令 | 备注 |
|---|---|---|---|
| 对话 | <11 格 | `talk {npc}` | 会打开对话 UI（客户端本地） |
| 看商店 | <12 格 | `shop {npc}` → `shops` | 返回 `shopId` 与货架 |
| 购买 | <12 格 | `buy {shopId,slot}` | 需要钱（铜币） |
| 出售 | <12 格 | `sell {item,slot}` | — |
| 让 NPC 搬进某间房 | — | `homeroom {who,x,y}` | 原版 `moveRoom`，房间不合法直接拒 |

- 靠近 NPC 要**真的走过去**（用户明确要求：不要直接打开商店 UI 凭空买）。
- NPC 在坑里也能交易，但会挡路/掉下去；能救就救（建合法房间 + `homeroom`）。

## 5. 召唤物操作

- `minion` 查/召唤；召唤物会自己打怪，不需要瞄准。
- 召唤槽满了就换；召唤物消失（死亡/离开）要重新召。
- 召唤物不挡自己挥击，但会抢掉落位置（不影响拾取）。

## 6. 药水 / 增益使用策略

| 场合 | 用 | 时机 |
|---|---|---|
| 探索洞穴 | 治疗药水 | hp<60% |
| 打 Boss | 铁皮 + 再生 + 敏捷 + 治疗 | 开战前全部喝，治疗留 50% |
| 长途赶路 | 敏捷/迅捷 | 出发前 |
| 溺水风险 | 鱼鳃/水下呼吸 | 入水前 |
| 夜间野外 | 火把 + 治疗 | 常备 |

- 药水有冷却，别连喝；`state.player.buffs` 可查当前增益。
- 增益会随死亡消失（未验证），死后重新喝。

## 7. 一次动作的标准循环

```
1. 看（state/tile/scan）
2. 做一个小动作（≤1.5s 的量）
3. 立刻回读验证（tile/state/inventory）
4. 不符预期 → 换策略，不重复同一个失败动作
```
