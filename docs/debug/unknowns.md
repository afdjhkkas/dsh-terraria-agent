# 已知的未知（本世界 / 本轮调试）

> 这份文件回答一个问题：**"你还有哪些是不知道的？"**
> 注意：这里**故意**全是本世界/本轮的坐标与单次数据——它属于调试记录，
> 不进 `docs/kb/` 的六个库（那条界由 `npm run kb:lint` 守着）。
> 每条写三样：不知道什么 / 为什么重要 / 怎么测（一次能出结论的最小实验）。
> 优先级：**P0** = 不解决就推不动主线；**P1** = 有替代路线，但迟早要会；**P2** = 可后置。
> 状态只有两种：`未验证`（从没测过）、`测过但不成立`（有证据的失败）。
