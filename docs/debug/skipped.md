### S6 结论（已解决）

根因是**东墙上有一扇开着的门**。逐格探测房屋四条边的 32 个边界格：

```
non-solid perimeter: 3
["east(2130,273)=OpenDoor","east(2130,274)=OpenDoor","east(2130,275)=OpenDoor"]
```

`OpenDoor` 是**非实心**方块，洪水填充从这三个格子漏进外面的世界，于是 `box` 一路涨到 `[2125,2162,1,338]`、`tiles` 涨到 9001。
另外西侧那扇门在之前的下挖里被我挖掉了（三格全 air），等于同时开了第二个口子。

修复顺序（全部真机执行并回读）：

1. 用镐打掉西侧残留的 `ClosedDoor`（`mine` 一次会把 3 格门一起打掉）→ (2121,273..275) 变 air，人可以进屋。
2. 进屋到 (2128.2,278.7)，`mine` 打掉东侧 `OpenDoor`（2130,273..275 三格变 air）。
3. `place {type:1}` 把 (2130,275)(2130,274)(2130,273) 依次砌成 Stone —— 回读三格都是 `Stone`。
4. 回到 (2123.5,278.7)，`place {x:2121,y:275,type:10}` 重新装门 —— 回读 (2121,273..275) 都是 `ClosedDoor`。
5. `housediag {x:2125,y:274}` → **`valid:true, tiles:64, box:[2122,2129,272,279], missing:[]`**。

**教训**：`place` 对着 `OpenDoor` 放方块会返回 `armed:true` 但格子仍是 `OpenDoor`（多格家具不能被单格方块覆盖）；必须先打掉再用真方块砌。
