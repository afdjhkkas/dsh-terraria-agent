DshTerrariaBridge.tmod is built from the checked-in C# source with the local
tModLoader 2026.8.3.0 build tool. Rebuild it with the target tModLoader
installation before distributing a release build for another game version.

For a local install, run the repository's install-mod.ps1 script. It copies
this file to the current user's tModLoader Mods directory and backs up an
existing DshTerrariaBridge.tmod before replacing it.
