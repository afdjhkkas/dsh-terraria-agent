# 元自检（顶层固定流程，不属于任何知识库）

> 这份文件是**元规则**，只写一次、永久生效。
> 它不回答"这次任务是什么"，只回答"这次任务我到底够不够格开始动手"。
>
> 插入位置：**拿到检索出来的知识之后、生成任何移动/交互动作之前**。
> 与单轮自路由共存，同一个回合内完成，不额外开一次请求。

## 为什么有这一条

不是"某条命令忘了写"，而是"没人先问一遍"。

本项目的真实教训：玩家要求"去海边钓个鱼"，我直接开始规划走路和挥竿，
四个缺口（没有钓竿/鱼饵、海洋在几千格外、没有"抛竿+等随机时长+咬钩瞬间收杆"这种多阶段原语、
读不到浮标和咬钩状态）全部是**玩家替我发现的**。

如果先跑下面的五维核验，四个缺口会在动手前就列出来。
**要的是"缺陷发现"本身变成固定能力，而不是一个个任务被玩家试出来。**

## 五维核验（固定五项，顺序不许改）

| # | 维度 | 核验什么 | 不通过记作 |
|---|---|---|---|
| 1 | 规则核验 | 知识库里有没有**完整**描述这件事的机制（触发条件、判定、后果）。只查了一半不算有。 | 【知识缺口】 |
| 2 | 道具核验 | 完成它必需哪些物品/工具？对着当前背包核。缺一件就要说出**取得链**（合成配方 / 掉落来源 / 购买 / 挖矿）。 | 【道具缺口】 |
| 3 | 地形/路径核验 | 目标在哪、属于什么群系、沿途有什么危险、现有移动命令能不能安全抵达、有没有未知障碍（水/岩浆/落差）。 | 【路径缺口】 |
| 4 | 动作原语核验 | 整条动作序列能不能用**清单里真实存在的**命令拼出来。需要"等待随机时长""分阶段交互""抓取/捕捉""连续时序"而清单里没有对应原语时，算不通过。 | 【动作原语缺口】 |
| 5 | 状态读取核验 | 判定时机需要的状态（弹幕位置、咬钩、buff、实体 AI、箱子内容……）有没有对应**读取字段**。读不到判定条件就永远无法知道"什么时候该动手"。 | 【状态读取缺口】 |

第 4、5 维**必须**对着常驻能力清单核，不许凭记忆：

- 紧凑版：`AGENTS.md` 的能力块（每次都在上下文里）
- 完整版：`docs/capabilities-manifest.md`
- 机器版：`docs/capabilities.json`（`terraria_kb { manifest: true }` 可取）

清单里没有的命令名，一律视为**不存在**。

## 输出格式（固定，机器要解析）

第一行独占：

```
SELF_CHECK:
```

紧接着五行，编号与名称固定，`PASS` / `GAP` 二选一：

```
SELF_CHECK:
1 规则核验: PASS
2 道具核验: GAP 缺钓竿（木头8+铁锭8，铁砧合成）；鱼饵要虫网抓虫
3 地形/路径核验: PASS 海洋在世界端点，走过去约 1000 格，有落水风险
4 动作原语核验: GAP 没有"抛竿 → 等待随机时长 → 咬钩瞬间收杆"的多阶段原语
5 状态读取核验: GAP 读不到浮标弹幕与咬钩状态
```

- `GAP` 后面**必须**写"缺什么"，能写清怎么补就写"怎么补"。
- `PASS` 后面可以留空，也可以写一句依据。
- 五行缺一行 = 自检没做完 = 按不通过处理。

## 判定与出口

- **五项全 PASS** → 才允许生成动作序列。
- **任意一项 GAP** → **禁止生成任何移动/交互动作**，先输出下面两块：

```
【自检未通过】缺口 N 项，先不动手：
- 【道具缺口】…
- 【动作原语缺口】…

你可以选：
分支A：先补齐条件再执行原目标（我先把前置任务列出来，前置任务同样要过五维）
分支B：放弃这个任务
```

分支 A 的前置任务也要跑一遍五维；前置任务自己过不去时就继续往下拆，直到全 PASS 或者拆到"清单里真的没有"为止。
拆到没有的时候说清楚"要等新能力"，不要假装用别的命令凑。

## 禁止事项

- 禁止编造清单里没有的命令、参数、读取字段、游戏规则。
- 禁止把"大概还能用 / 应该差不多"当 PASS。**不确定就是 GAP。**
- 禁止先动手再补自检。
- 禁止把自检写成形式：每一维都要能说出依据（哪条库规则 / 哪个命令 / 哪个返回字段）。
- 计划里出现的每个命令名，必须能在能力清单里找到（`terraria_kb { selfcheck }` 会做机器校验）。

## 三层配合

| 层 | 作用 | 位置 |
|---|---|---|
| 路由 | 这次要查哪几个库 | `prompts/self-route.md` + `prompts/intent-router.md` |
| **元自检** | 这次到底够不够格动手 | 本文件 |
| 能力清单 | 我真实拥有什么 | `AGENTS.md` 能力块 / `docs/capabilities-manifest.md` |

轻量任务（查坐标、读背包、走两步）可以只留一行 `SELF_CHECK: skip（只读，不涉及动作缺口）`；
但**只要会改变世界或依赖随机时机，就必须走满五项**。
